# Состояние системы

Страница для того, чтобы одним взглядом увидеть текущее «здоровье» сервера: насколько заполнен диск,
работают ли транки, есть ли интернет/DNS, состояние SIP-транспортов и количество зарегистрированных
устройств. Отсюда же можно очистить диск и перезагрузить/выключить сервер.

## Где находится
Меню: **Система → Состояние системы**. Кто видит: только пользователь с правами `*` (полный
администратор).

## Основные понятия

- **Диск** — общий объём использованного/свободного места и распределение по категориям (записи
  звонков, резервные копии, файлы миграции, голосовая почта, журналы); некоторые категории помечены как
  **не очищаемые вручную**.
- **Транки** — состояние каждого транка (работает/проблема) и причина, если она есть.
- **Интернет** — наличие внешнего соединения, работа DNS, задержка (мс) и проверяемый адрес.
- **SIP-интерфейс** — работает ли служба Asterisk, какие транспорты (UDP/TLS) привязаны к какому адресу,
  сколько устройств зарегистрировано.
- **Очистка диска** — освобождение места за счёт удаления старых записей звонков, лишних резервных копий
  и загруженных файлов миграции FreePBX; перед удалением **заранее показывается (preview)**, сколько
  места освободится.
- **Перезагрузка / выключение** — удалённая перезагрузка или выключение сервера; если заблокировано по
  причине (`readonly_reason`), кнопки не работают.

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Удалить записи старше скольких дней | Порог очистки записей звонков | 180 дней |
| Оставить только последние N копий | Порог очистки локальных резервных копий | 3 шт. |
| Загруженные файлы миграции FreePBX | Если отмечено — удаляются все загруженные комплекты | По умолчанию отмечено |
| Hostname (подтверждение) | Для подтверждения перезагрузки/выключения нужно ввести точно | — |

## Как это делается

### Просмотр состояния
1. При открытии страницы карточки диска, транков, интернета и SIP загружаются автоматически.
2. Если есть проблема (например разорвана связь с транком) — соответствующая карточка показывается
   **красным/предупреждающим** цветом.

### Очистка диска
1. Нажмите кнопку **Очистить диск** (если диск заполнен, кнопка отображается красной).
2. Отметьте нужные пункты: старые записи звонков (сколько дней), лишние резервные копии (сколько
   последних сохранить), загруженные файлы миграции.
3. После каждого изменения система автоматически показывает, сколько места освободится (объём и
   количество файлов).
4. Нажмите **Удалить** и подтвердите — это действие **невозможно отменить**.

### Перезагрузка или выключение сервера
1. Нажмите кнопку **Перезагрузить** или **Выключить**.
2. В открывшемся окне точно впишите **hostname** сервера для подтверждения (чтобы избежать случайного
   нажатия).
3. После подтверждения действие выполняется не сразу, а с небольшой задержкой (в секундах) — об этом
   выводится сообщение.

## Советы и ограничения

> [!WARNING]
> Перезагрузка/выключение разрывает все **активные звонки**. После **выключения** сервер придётся
> включить вручную (физически или через панель управления).

> [!TIP]
> Перед очисткой диска проверьте объём, показанный в **preview** — особенно перед уменьшением количества
> резервных копий убедитесь, что нужных копий остаётся достаточно.

- Если кнопки перезагрузки/выключения **отключены**, на странице показывается причина
  (`readonly_reason`) — например, может выполняться другое системное действие (резервное
  копирование/перенос).
- Некоторые категории диска (например журналы) помечены как **не очищаемые вручную** — они не удаляются
  через эту страницу.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| «Не удалось загрузить» | Нет связи с сервером | Нажмите **Повторить** |
| Диск заполнен (красный) | Записи звонков/резервные копии заняли много места | Удалите старые файлы через **Очистку диска** |
| Транк красный/проблема | Нет связи с провайдером | Прочитайте текст причины, проверьте настройки [SIP и сети](/docs/sip) |
| Интернет «Нет соединения»/DNS не работает | Проблема сети сервера или не работает служба DNS | Проверьте сетевые настройки сервера |
| «Имя хоста не совпадает» | В поле подтверждения введён неверный текст | Введите hostname точно, с учётом регистра |
| Кнопка перезагрузки/выключения отключена | Блокировано с `readonly_reason` | Устраните указанную причину и попробуйте снова |
