# Исходящие маршруты

Исходящие маршруты определяют, через какой(ие) транк(и) и с каким изменением (вырезание/добавление
префикса) набранный с внутреннего номера номер уходит во внешнюю сеть. Маршруты работают как список,
упорядоченный по приоритету — используется первый подходящий сверху маршрут.

## Где находится

Меню: **Подключение → Исходящие маршруты**. Кто видит: право `connect:view`. Добавление/редактирование/
удаление/изменение порядка — право `connect:edit`; при его отсутствии показывается подсказка **«У вас
нет прав на управление исходящими маршрутами — доступны только просмотр и тест»** (право на тест работает
даже при наличии только права просмотра).

## Основные понятия

- **Приоритет** — маршруты проверяются сверху вниз; для набранного номера используется первый
  подходящий маршрут. Порядок можно изменить перетаскиванием (drag).
- **Правила шаблона** — в каждом маршруте может быть несколько строк: **Добавить в начало** (значение,
  добавляемое перед номером), **Префикс** (вырезаемая часть), **Шаблон** (каким номерам соответствует,
  например `998XXXXXXXXX`), и свой **CallerID** для строки.
- **Цепочка транков** — через какие транк(и) уходит звонок: первый — **Основной**, остальные —
  **Резерв 1**, **Резерв 2** и т.д. — если основной не работает, пробуется следующий. Каждый транк
  показывается вместе со статусом работоспособности.
- **PIN и набор PIN-кодов** — два отдельных способа защиты могут работать в одном маршруте одновременно:
  обычное поле **PIN** (один код, привязанный к этому маршруту) и отдельный **набор PIN-кодов**
  (управление несколькими кодами/пользователями). Достаточно **любого из двух** — если верно введён хотя
  бы один, звонок проходит.
- **Международные звонки** — отдельный переключатель; при включении показывается предупреждение о риске
  toll-fraud (больших расходов при неправомерном использовании).
- **Кто может использовать** — маршрут можно ограничить значением **Все** (все внутренние номера) или
  списком **Выбранные** внутренних номеров.
- **Тестировщик (симулятор)** — встроенный инструмент: выбрав внутренний номер и номер, показывает в
  реальном времени, как маршрут действительно сработает (разрешено/отклонено, какая цепочка транков,
  причины пошагово).

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| **Название** | Имя маршрута для распознавания | — (обязательно) |
| **Включён** | Временное отключение маршрута | по умолчанию: включён |
| **Правила шаблона** | Строки Добавить в начало / Префикс / Шаблон / CallerID | Шаблон: `998XXXXXXXXX` |
| **Цепочка транков** | Порядок транков, используемых для выхода | Первый — Основной |
| **Исходящий Caller ID** | Переопределение стандартного caller ID транка для этого маршрута | пусто — используется caller ID транка |
| Переключатель **Приоритетный** | CallerID этого маршрута важнее собственного caller ID внутреннего номера | по умолчанию: отключено |
| **PIN** + значение PIN | Требовать код для этого маршрута | только цифры, 4–12 знаков |
| **Набор PIN-кодов** | Использовать отдельно управляемый набор кодов | по умолчанию: не выбрано |
| **Международные звонки** | Разрешить выход на международные направления | по умолчанию: отключено |
| **Кто может использовать** | **Все** или **Выбранные** внутренние номера | по умолчанию: Все |

## Как это делается

### Добавление нового исходящего маршрута
1. Нажмите кнопку **Новый маршрут**.
2. Введите **Название**.
3. Укажите хотя бы одно правило **Шаблон** (например `998XXXXXXXXX`), при необходимости заполните
   **Добавить в начало**/**Префикс**.
4. В **Цепочке транков** выберите хотя бы один транк.
5. Нажмите **Добавить**.

### Настройка шаблона и цепочки транков
1. Откройте маршрут для редактирования.
2. Через **Добавить правило** введите дополнительные строки шаблона; при ошибке в строке она подчёркнута
   красным.
3. В **Цепочке транков** добавьте/удалите транки, измените порядок перетаскиванием — первый становится
   **Основным**.
4. Нажмите **Сохранить**.

### Защита с помощью PIN или набора PIN-кодов
1. Откройте маршрут для редактирования.
2. Включите **PIN** и введите код, и/или выберите существующий **набор PIN-кодов**.
3. Нажмите **Сохранить** — теперь при наборе через этот маршрут будет запрашиваться код.

### Включение международных звонков
1. Откройте маршрут для редактирования.
2. Включите переключатель **Международные звонки** — прочитайте предупреждающий баннер.
3. Нажмите **Сохранить**.

### Ограничение использования маршрута внутренними номерами
1. Откройте маршрут для редактирования.
2. В **Кто может использовать** выберите **Выбранные**.
3. Добавьте нужные внутренние номера в список (ненужные снимите отметкой).
4. Нажмите **Сохранить**.

### Использование тестировщика
1. В боковой панели страницы в разделе **Тестировщик** введите внутренний номер и проверяемый номер.
2. Нажмите кнопку **Проверить**.
3. Результат: **Разрешено**/**Отклонено**, какая цепочка транков использована и список причин пошагово.

### Изменение порядка маршрутов по приоритету
1. В списке возьмитесь за маркер перетаскивания нужного маршрута и перетащите его на другое место.
2. Новый порядок сохраняется автоматически.

### Удаление маршрута
1. В строке нажмите значок **Удалить**.
2. Если маршрут ещё используется (например, указан у какого-то внутреннего номера), система покажет
   места использования и не разрешит удаление — сначала удалите их оттуда.

## Советы и ограничения

> [!WARNING]
> Перед включением **Международных звонков** будьте осторожны — неправомерное использование (например,
> скомпрометированный внутренний номер) может привести к большим международным расходам (toll-fraud).
> Разрешайте доступ только действительно нужным внутренним номерам.

> [!TIP]
> Если PIN и набор PIN-кодов используются в одном маршруте вместе, достаточно верно ввести **любой** из
> них — знать оба не требуется.

> [!TIP]
> Если **Исходящий Caller ID** оставить пустым, используется стандартный caller ID транка; заполняйте
> его только если для этого маршрута нужен особый номер.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Строка шаблона подчёркнута красным | Шаблон записан в неверном формате | Проверьте и исправьте часть перед указанным символом |
| «Нужен хотя бы один транк» | Цепочка транков оставлена пустой | Добавьте хотя бы один транк в **Цепочку транков** |
| Не удаётся удалить маршрут | Маршрут ещё используется где-то (например, у внутреннего номера) | Сначала удалите его из указанного списка использования |
| Звонок «Отклонён» (в тестировщике) | Не подошёл шаблон, транк не работает или неверный PIN | Посмотрите пошаговые причины в тестировщике и исправьте соответствующее поле |
| Не проходит на международный номер | Отключены **Международные звонки** | Включите их в маршруте (прочитав предупреждение) |
