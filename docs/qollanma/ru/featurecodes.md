# Коды функций

Такие функции, как голосовая почта, DND, переадресация звонков, перехват, парковка и подобные им, можно
использовать с внутреннего номера, набрав `*`-код (например `*97` — голосовая почта). Код каждой функции
изменяется здесь, при необходимости можно полностью её отключить.

## Где находится
Меню: **Система → Коды функций**. Кто видит: таблицу может видеть любой, но изменять код и статус
включения/отключения может только пользователь с правом `*` (полный администратор).

## Основные понятия

- **Функция** — действие, вызываемое набором кода с телефона: Голосовая почта (`*97`), Голосовая почта
  другого внутреннего номера (`*98`), Переключение DND (`*76`), Включение/отключение постоянной
  переадресации (`*72`/`*73`), Включение/отключение переадресации при занятости (`*90`/`*91`), Перехват по
  группе (`*8`), Прямой перехват (`**`), Парковка (`*70`), Эхо-тест (`*43`), Говорящие часы (`*60`),
  Включение/отключение Follow Me (`*21`), Вход/выход из очереди (`*45`), Пауза в очереди (`*46`),
  Интерком (автоответ, `*80`), Включение/отключение ожидания звонка (`*56`/`*57`). Сами функции очередей и
  интеркома управляются в соответствующих разделах (Очереди, настройки внутреннего номера) — на этой
  странице можно только изменить код/вернуть к стандартному.
- **Код** — последовательность из 1–6 символов (цифры, `*`, `#`), начинающаяся с `*`, например `*97`.
- **Стандартный код** — у каждой функции есть свой стандартный код; если изменённый код отличается от
  стандартного, появляется кнопка **вернуть к стандартному значению**.
- **Конфликт** — конфликтом считается не только случай, когда два кода **полностью совпадают**, но и
  когда один является **префиксом** другого (например `*7` и `*72`) — Asterisk не может надёжно различить
  их. В этом случае система отказывает в сохранении.
- **Включено/отключено** — если функция полностью отключена, её код больше ни к чему не подключается.

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Функция | О каком действии идёт речь (не изменяется) | — |
| Код | `*` + 1–6 символов (цифры/`*`/`#`) | `*97` |
| Включено | Включает/отключает функцию | — |

## Как это делается

### Изменение кода
1. В строке нужной функции нажмите значок карандаша.
2. Введите новый код (формат: начинается с `*`, 1–6 символов).
3. Нажмите значок (✓) — сохранится. Для отмены нажмите ✕.

### Возврат кода к стандартному значению
1. Если код отличается от стандартного, в строке появляется значок **сброса** — нажмите его.
2. Код сразу вернётся к стандартному значению.

### Включение/отключение функции
1. В нужной строке нажмите переключатель **Включено**.

## Советы и ограничения

> [!WARNING]
> Двум функциям нельзя назначить одинаковый **или являющийся префиксом друг друга** код (например `*7`
> и `*72` одновременно существовать не могут) — система вернёт ошибку «этот код конфликтует с другой
> функцией».

> [!TIP]
> После изменения кода сообщите пользователям внутренних номеров новый код — старый код больше не
> работает.

- Формат кода жёстко задан: только `*`, цифры и `#`, длина 1–6 символов.
- Право на просмотр есть у всех, но изменение разрешено только полному администратору — остальным таблица
  только отображается, кнопки редактирования не показываются.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| «Неверный код» | Формат не подходит (слишком длинный/неверный символ) | Введите код, начинающийся с `*`, только цифры/`*`/`#`, 1–6 символов |
| «Этот код конфликтует с другой функцией» | Этот код уже назначен другой функции или является её префиксом/продолжением | Выберите другой код или сначала измените предыдущий |
| «Не удалось сохранить» | Ошибка сервера | Повторите попытку |
| Кнопки редактирования не видны | Нет прав полного администратора | Запросите у администратора право `*` |
