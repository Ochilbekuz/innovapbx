# Paging / Intercom

**Группа пейджинга** — позволяет набором одного номера одновременно транслировать голосовое сообщение на
несколько внутренних номеров (аппаратов). Например: создав группу «Общее объявление» и подключив к ней
телефоны всех отделов, можно, набрав один номер, объявить всему офису «Начался обеденный перерыв».

## Где находится

Меню: **Приложения → Paging / Intercom**. Кто видит: пользователи с правом `routing` редактируют,
остальные только просматривают (с предупреждением **«У вас нет прав на управление группами
пейджинга»**) — хотя в меню экран показан в разделе «Приложения».

## Основные понятия

- **Номер** — при наборе этого номера соединение устанавливается со всеми участниками одновременно
  (воспроизводится голосовое сообщение).
- **Двусторонний** — если включено, участники тоже могут отвечать и говорить; если отключено — только
  одностороннее объявление (участники слышат, но не могут ответить).
- **Пропускать занятых** — если включено, занятому участнику сообщение не отправляется.
- **Сигнал** — перед началом сообщения проигрывается короткий сигнал (beep).
- **Интерком** (`*80<внутренний номер>`) — в отличие от группы пейджинга, код функции для прямого
  соединения с конкретным внутренним номером с автоматическим ответом (по умолчанию `*80`, можно
  изменить в [Кодах функций](/docs/featurecodes)).

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Имя | Название группы | Не более 128 символов |
| Номер | Номер для набора, соединяющий с группой | 1–10 символов `0-9*#` |
| Двусторонний | Могут ли участники отвечать и говорить | По умолчанию — отключено (одностороннее) |
| Пропускать занятых | Занятому участнику сообщение не отправляется | По умолчанию — включено |
| Сигнал | Короткий сигнал перед сообщением | По умолчанию — включено |
| Участники | Внутренние номера, на которые транслируется сообщение | Выбираются из списка внутренних номеров |

## Как это делается

### Создание новой группы пейджинга
1. Нажмите **Новая группа**, введите имя и номер.
2. Отметьте нужных участников (внутренние номера).
3. При необходимости измените настройки **Двусторонний**, **Пропускать занятых**, **Сигнал**.
4. Нажмите **Добавить**.

### Редактирование группы
1. Нажмите кнопку редактирования в строке, измените нужные поля, нажмите **Сохранить**.

### Звонок в группу
1. С любого внутреннего телефона наберите номер группы — соединение установится со всеми участниками
   одновременно.

### Прямое соединение с номером через интерком
1. Наберите `*80<внутренний номер>` (например `*80205`) — аппарат собеседника автоматически ответит
   (если поддерживает интерком).

### Удаление
1. Нажмите значок корзины в конце строки, подтвердите — группа будет удалена полностью.

> [!WARNING]
> Если за одним внутренним номером в группе пейджинга зарегистрировано несколько устройств (например
> настольный телефон + софтфон), пока звонит **только первое зарегистрированное устройство** — потому
> что приложение Asterisk `Page()` заранее проверяет «device state» каждого адреса и не принимает
> сочетание «один номер — несколько устройств» (обнаружено в 1.0.15, пока не исправлено). Учитывайте это,
> добавляя в группу пейджинга сотрудников с несколькими устройствами.

> [!TIP]
> Для объявления только на прослушивание (например динамики в цеху) — отключите **Двусторонний**, иначе
> у всех участников откроется микрофон и может добавиться шум.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| У сотрудника с несколькими устройствами звонит только один телефон | Группы пейджинга пока доходят только до первого устройства (известное ограничение) | Зарегистрируйте основное используемое устройство сотрудника первым |
| Сообщение отправляется и занятому участнику | Отключено **Пропускать занятых** | Включите эту опцию в настройках группы |
| Интерком не работает | Устройство собеседника не поддерживает автоответ или код изменён | Проверьте настройки устройства и текущий код в [Кодах функций](/docs/featurecodes) |
| Не удаётся удалить группу | Используется где-то ещё (маршрут, IVR) | Сначала удалите эти связи |
