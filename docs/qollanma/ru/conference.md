# Конференц-залы

**Конференция** — «зал», в котором одновременно общаются несколько внутренних/внешних звонков. Например,
для еженедельного совещания сотрудники набирают один номер, вводят PIN и присоединяются к залу.

## Где находится

Меню: **Приложения → Конференц-залы**. Кто видит: пользователи с правом `apps` редактируют, остальные
только просматривают.

## Основные понятия

- **Номер** — номер, который набирается для присоединения к залу; если оставить пустым, назначается
  автоматически.
- **PIN** — пароль для обычных участников (необязательно).
- **PIN администратора** — отдельный пароль для модератора; человек, вошедший как модератор, получает
  право управлять другими участниками.
- **Лимит участников** — сколько человек может одновременно находиться в зале.
- Столбец **Сейчас** — показывает в реальном времени, сколько человек сейчас в зале.

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Название | Название зала | Не более 128 символов |
| Номер | Код для присоединения к залу | Пусто — назначается автоматически; 2–10 символов `0-9*#` |
| PIN | Пароль для участников | Необязательно, 4–8 цифр |
| PIN администратора | Пароль для модератора | Необязательно, 4–8 цифр |
| Запись разговора | Запись разговора конференции | — |
| Лимит участников | Максимальное число участников | Необязательно, 2–100, пусто — без ограничения |

## Как это делается

### Создание новой конференции
1. Нажмите **Добавить конференцию**, введите название.
2. Введите номер вручную или оставьте пустым для автоматического назначения.
3. При необходимости укажите PIN и PIN администратора, лимит участников, включите/отключите запись
   разговора.
4. Нажмите **Добавить**.

### Подключение конференции к входящему маршруту/IVR
1. На странице [Входящих маршрутов](/docs/inbound) направьте адрес DID на эту конференцию, либо выберите
   её как адрес в кнопке IVR.
2. Внутренние сотрудники также могут присоединиться, набрав номер зала напрямую.

### Назначение прав модератора
1. Установите для конференции **PIN администратора** и сообщите этот PIN модератору — при входе с этим
   PIN он получит отдельные права управления.

### Удаление
1. Нажмите значок корзины в конце строки.
2. Если конференция используется где-то ещё (маршрут, IVR), удаление блокируется — сначала удалите эти
   связи.

> [!TIP]
> Задайте разные PIN для обычных участников и модератора — тогда модератор всегда будет узнаваться
> отдельно и получит возможность управления.

> [!WARNING]
> После заполнения **Лимита участников** звонки, пытающиеся присоединиться, будут отклонены — для важных
> совещаний установите достаточный лимит или оставьте его пустым (без ограничения).

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Ошибка «номер занят» | Этот номер уже используется на другом адресе | Выберите другой номер или оставьте пустым для автоматического |
| Участник не может войти в зал | Достигнут лимит участников | Увеличьте лимит или сделайте его пустым (без ограничения) |
| PIN отклоняется как неверный | PIN не состоит из 4–8 цифр | Введите PIN в правильном формате |
| Не удаётся удалить конференцию | Используется в маршруте/IVR | Сначала удалите эти связи |
