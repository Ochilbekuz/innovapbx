# Живой мониторинг

Живой мониторинг — экран для супервайзера или администратора: показывает в реальном времени, кто сейчас
с кем разговаривает, сколько человек ждёт в очереди и какой внутренний номер занят/свободен, при
необходимости позволяет прослушать звонок, подсказать или подключиться к нему.

## Где находится

Меню: **Обзор → Живой мониторинг**. Кто видит: роль с правом `monitor:view`. Для наблюдения
(прослушивание/подсказка/подключение) нужно соответствующее право на запись (`monitor:edit`).

## Основные понятия

- **Режимы наблюдения (spy)** — способы незаметно подключиться к активному звонку:
  - **Прослушать** — только слушает, не влияет на разговор.
  - **Подсказать** — говорит только своему оператору, звонящий не слышит.
  - **Подключиться** — полностью присоединяется к разговору как третья сторона, все слышат.
- Данные страницы обновляются автоматически; счётчики длительности идут в реальном времени, посекундно.
- Если связь с Asterisk прерывается, в верхней части страницы появляется предупреждение **«Нет связи с
  Asterisk»**, и данные временно перестают обновляться.

## Поля

Таблица **Активные звонки**:

| Столбец | Что показывает |
|---|---|
| Значок направления | Иконка входящего / исходящего / внутреннего звонка |
| **От кого** / **Кому** | Номера сторон звонка |
| **Статус** | **Звонит**, **Разговор** или **На удержании** |
| **Длительность** | Время, прошедшее с начала звонка (считается в реальном времени) |
| Кнопки наблюдения | **Прослушать** / **Подсказать** / **Подключиться** |

Карточки **Очереди** (отдельная карточка для каждой очереди): **В ожидании** (количество ожидающих),
**Макс. ожидание**, **Операторы** (сколько операторов активны из общего числа).

Сетка **Статус внутренних номеров** — для каждого номера: номер, имя и значок статуса: **Свободен**,
**Звонит**, **Занят**, **Не беспокоить**.

## Как это делается

### Наблюдение за активным звонком
1. В таблице **Активные звонки** найдите нужную строку.
2. Нажмите одну из трёх кнопок справа: **Прослушать**, **Подсказать** или **Подключиться**.
3. При успешном запуске появится уведомление **«Наблюдение начато»**.

### Проверка статуса внутреннего номера
1. Посмотрите на раздел **Статус внутренних номеров** в нижней части страницы.
2. На карточке каждого номера текущий статус показывается цветным значком (например при занятости —
   красный значок **Занят**).

## Советы и ограничения

> [!WARNING]
> Для наблюдения ваша учётная запись должна быть привязана к внутреннему номеру — иначе при нажатии
> кнопки появится сообщение **«Ваш аккаунт не привязан к номеру — наблюдение недоступно»**.

> [!TIP]
> Будьте осторожны с режимом **Подключиться** — в этом режиме вы полностью присоединяетесь к разговору
> как участник, и все стороны вас слышат.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Предупреждение «Нет связи с Asterisk» | Прервана связь со службой Asterisk | Проверьте состояние системы на [Панели управления](/docs/dashboard); если не помогает — обратитесь к администратору сервера |
| «Не удалось начать наблюдение» | Звонок уже завершился или ваша учётная запись не привязана к номеру | Обновите таблицу, проверьте, что к вашей учётной записи привязан внутренний номер |
| Список внутренних номеров пуст | Ещё не создан ни один внутренний номер | Добавьте номер в разделе [Внутренние номера](/docs/extensions) |
