# Специальные адреса

Этот раздел управляет двумя вещами: **Другие адреса** — отдельные коды набора, не входящие в список
внутренних номеров (например прямое подключение к факсимильному аппарату), и **Спецкоды** — ярлыки,
которые при наборе с телефона (например `*501`) сразу соединяют с указанным адресом.

## Где находится

Меню: **Маршрутизация → Специальные адреса**. Кто видит: пользователи с правом `routing` редактируют,
остальные только просматривают.

## Основные понятия

- **Другой адрес** — обычная «строка набора» (dial string) — отображается в списке адресов в IVR/условии
  рабочего времени и т.д., но отсутствует в таблице внутренних номеров (например аналоговый факс-порт).
- **Спецкод** — если пользователь набирает на телефоне (например `*501`), происходит прямое соединение с
  указанным адресом (внутренний номер, очередь, IVR и т.д.). В любой момент можно включить/отключить.

## Поля

### Другой адрес

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Название | Название адреса | — |
| Код набора | Код, который набирает Asterisk для соединения | Например `0022`; только `0-9*#+`, 1–32 символа, не должен конфликтовать с внутренними номерами |

### Спецкод

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Название | Название кода | — |
| Код | Код набора | Начинается с `*`, 1–6 символов (`*501`), либо обычный код из 1–10 цифр |
| Адрес | Куда переходит при наборе кода | Внутренний номер, очередь, IVR, группа вызова, конференция, объявление, другой адрес и т.д. |
| Включено | При отключении код не работает, но остаётся сохранённым | По умолчанию включено |

## Как это делается

### Добавление другого адреса
1. На вкладке **Адреса** нажмите **Добавить адрес**.
2. Введите название и код набора (убедитесь, что он не конфликтует с другим внутренним номером/кодом).
3. Нажмите **Добавить**.

### Добавление спецкода
1. На вкладке **Спецкоды** нажмите **Добавить код**.
2. Выберите название, код (например `*501`) и адрес.
3. Нажмите **Добавить** — код сразу становится активным.

### Временное отключение спецкода
1. Откройте код для редактирования, отключите переключатель **Включено**, нажмите **Сохранить**.
2. Сам код не удаляется — просто не работает, при необходимости его можно снова включить.

### Удаление
1. Нажмите значок корзины в конце строки.
2. Если другой адрес используется в другом месте, удаление блокируется — сначала удалите эти связи.

> [!TIP]
> Спецкоды удобны для быстрых ярлыков: например `*0` — прямое соединение с приёмной, `*99` — с дежурной
> технической службой.

> [!WARNING]
> Спецкод не должен конфликтовать с другими [кодами функций](/docs/featurecodes) (например системными
> кодами вроде `*97`, `*98`) — совпадать или быть их префиксом (например `*7` и `*72`). При конфликте
> панель не сохранит код: при конфликте с другой включённой функцией появляется сообщение **«Этот код
> конфликтует с другой функцией»**, при конфликте с внутренним номером/адресом — **«Этот код конфликтует
> с внутренним номером/адресом»**.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Код набора не сохраняется | Неверный формат (запрещённый символ) или пустое значение | Введите только `0-9*#+`, 1–32 символа |
| При наборе спецкода ничего не происходит | Отключено **Включено** | Отредактируйте код и включите его |
| Не удаётся удалить другой адрес | Используется в другом месте (IVR, условие рабочего времени и т.д.) | Сначала удалите эти связи |
