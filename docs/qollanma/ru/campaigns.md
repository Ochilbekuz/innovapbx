# Кампании

**Кампания** — система сама совершает автоматический обзвон большого числа номеров из списка в заданное
окно дней/времени. Например: кампания «Напоминание о задолженности» звонит 500 клиентам в рабочие дни с
09:00 до 20:00, проигрывает аудиосообщение и соединяет с оператором тех, кто нажал «1».

## Где находится

Меню: **Приложения → Кампании**. Кто видит: пользователи с правом `apps` редактируют, остальные только
просматривают (с предупреждением **«У вас нет прав на управление кампаниями»**).

## Основные понятия

- **Тип (mode)** — два варианта: **Аудиосообщение** (если клиент отвечает, проигрывается аудио, по
  желанию — «1» соединяет с оператором, «9» запрещает дальнейшие звонки) или **Соединить с оператором**
  (как только клиент отвечает, он сразу соединяется с внутренним номером/очередью/группой).
- **Статус** — кампания находится в одном из пяти статусов: **Черновик** → **Идёт** → **На паузе**/
  **Завершена**/**Остановлена**. Редактировать/удалять можно только в статусах **Черновик** и **На
  паузе** — во время работы (`running`) изменить нельзя.
- **Окно звонков** — дни недели + время начала/окончания (время Ташкента). Если время окончания раньше
  начала (например `22:00`–`02:00`), окно продолжается через полночь.
- **Скорость и попытки** — сколько звонков идёт одновременно параллельно, сколько раз и через какой
  интервал повторяется звонок, если занято/нет ответа.
- **Контакты** — список номеров, загружаемый через CSV; у каждого отдельно отслеживается статус (в
  очереди, набор, повтор, выполнено, не дозвонились, пропущен) и результат звонка.
- **Отказавшиеся (opt-out)** — номера, нажавшие «9», полностью попадают в список отказов и **не
  набираются и в других кампаниях**; этот список сохраняется даже после удаления кампании.

## Поля

### Что услышит клиент

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Название | Название кампании | Не более 80 символов |
| Тип | **Аудиосообщение** или **Соединить с оператором** | — |
| Аудиосообщение | Файл, проигрываемый при типе «Аудиосообщение» | Выбирается из [Аудиотеки](/docs/audio), обязательно |
| С кем соединять | Внутренний номер, очередь или номер группы | Обязательно при типе «Соединить с оператором»; при «Аудиосообщение» нужно только если включено «1» |
| «1» — соединить с оператором | После сообщения при нажатии «1» соединяет с указанным выше номером | Отображается только при типе «Аудиосообщение» |
| «9» — больше не звонить | Номер, нажавший «9», попадает в список отказов | По умолчанию — включено |
| Номер, видимый клиенту | Номер, показываемый как CallerID | Пусто — номер из настроек транка, 3–15 цифр |

### Когда совершать звонки

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Начало / Конец | Окно звонков (время Ташкента) | По умолчанию `09:00`–`20:00` |
| Дни недели | В какие дни совершаются звонки | По умолчанию — с понедельника по субботу |

### Скорость и попытки

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Одновременно | Количество параллельных звонков | 1–30, по умолчанию `2` |
| Попыток | Сколько раз повторяется набор при занято/нет ответа | 1–5, по умолчанию `3` |
| Интервал, минуты | Ожидание перед повторной попыткой | 1–1440, по умолчанию `600` минут (10 часов) |
| Звонить, секунд | Сколько секунд звонит при каждой попытке | 10–30, по умолчанию `25` |

## Как это делается

### Создание новой кампании
1. Нажмите **Новая кампания**.
2. Укажите **Название** и выберите **Тип**.
3. Для «Аудиосообщение» — выберите аудио, при необходимости включите/отключите кнопки «1»/«9».
   Для «Соединить с оператором» — заполните поле **С кем соединять**.
4. Укажите окно звонков и дни недели, при необходимости измените настройки скорости/попыток.
5. Нажмите **Создать** — кампания создаётся в статусе **Черновик**, теперь нужно загрузить номера.

### Загрузка номеров через CSV
1. Откройте кампанию и перейдите в раздел **Загрузка номеров**.
2. Выберите CSV-файл или вставьте текст вручную. В каждой строке: номер, имя (необязательно); разделитель
   — запятая или точка с запятой; первая строка может быть заголовком.
3. Повторяющиеся и некорректные строки определяются автоматически, их количество показывается.
4. Если включить **Заменить прежний список** — все прежние контакты и их результаты будут удалены и
   заменены новым списком.
5. Нажмите **Загрузить**.

> [!WARNING]
> В завершённую или остановленную кампанию нельзя добавить новые номера — в этом случае создайте новую кампанию.

### Запуск/пауза/остановка кампании
1. У кампании в статусе **Черновик** или **На паузе** нажмите **Запустить** — статус перейдёт в
   **Идёт**.
2. Чтобы временно остановить работающую кампанию, нажмите **Пауза** — затем можно продолжить кнопкой
   **Продолжить**, оставшиеся контакты сохранятся.
3. Нажатие **Остановить** — **необратимое** действие: кампания переходит в статус **Остановлена** и
   запустить её заново нельзя (для временной остановки используйте Паузу).

### Редактирование
1. Откройте кампанию в статусе **Черновик** или **На паузе**, измените нужные поля, нажмите **Сохранить**.
2. Кампанию в статусе **Идёт** редактировать нельзя — сначала переведите её в **Паузу**.

### Отслеживание контактов
1. В таблице **Контакты** внутри кампании видны статус каждого номера, количество попыток, время
   последней/следующей попытки и результат (ответил, занято, не ответил, в чёрном списке и т.д.).
2. Можно фильтровать по статусу и искать по номеру/имени.
3. С помощью **Скачать CSV** можно экспортировать текущий список контактов вместе с результатами.

### Удаление
1. Кампанию в статусе **Черновик** или **На паузе** можно удалить — нажмите значок корзины в конце строки.
2. Кампания, все контакты и их результаты удаляются полностью; сохраняется только **список отказов
   (opt-out)**.
3. Кампанию в статусе **Идёт** удалить нельзя — сначала остановите её или поставьте на паузу.

> [!TIP]
> Настройте окно звонков на удобное для клиентов время (например рабочие дни 09:00–20:00) — ночные или
> раннеутренние автоматические звонки могут вызвать жалобы.

> [!WARNING]
> Номера, отказавшиеся кнопкой «9», автоматически пропускаются **во всех** последующих кампаниях — этот список нельзя восстановить через панель.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Кампанию не удаётся редактировать/удалить | Статус **Идёт** | Сначала поставьте на **Паузу**, затем редактируйте/удаляйте |
| При загрузке CSV много номеров помечено «некорректно» | Номера в неверном формате или вне диапазона 3–15 цифр | Указывайте номера только из цифр, правильной длины |
| Кампания не запускается | Текущее время вне указанного окна/дня звонков | Проверьте окно и дни недели, расширьте при необходимости |
| Клиент всегда получает результат «в чёрном списке» | Номер в [Чёрном списке](/docs/blacklist) или ранее нажал «9» | Проверьте чёрный список или прежний статус отказа |
| При нажатии «1» не соединяет с оператором | Поле **С кем соединять** пустое или указано неверно | Заполните поле — должен быть внутренний номер, очередь или номер группы |
