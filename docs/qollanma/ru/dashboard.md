# Панель управления

Панель управления — первый экран, который открывается при входе в систему: показывает, работают ли
Asterisk и база данных, сколько звонков было сегодня, кто сейчас разговаривает и где есть проблема, всё
одним взглядом. Данные автоматически обновляются каждые 10 секунд.

## Где находится

Меню: **Обзор → Панель управления**. Кто видит: любая роль с правом `monitor:view` (обычно **admin**;
для специальных ролей — если дан доступ к области Monitoring). Для карточки **Парковка вызовов** внизу
дополнительно нужно право `apps:view` — без этого права карточка вообще не отображается (например, у
роли оператора).

## Основные понятия

- **Состояние системы** — состояние Asterisk, базы данных, свободного места на диске и каждого транка.
  Каждый показывается зелёным (`ok`) или красным (`crit`) цветом; при проблеме указывается короткая
  причина (например «Процесс Asterisk не отвечает»).
- **Оповещения** — отображаются сверху страницы только при наличии проблемы; нажатие переводит в
  соответствующий раздел.
- **Почасовой объём** — количество входящих/исходящих/пропущенных звонков за сегодня, столбчатая
  диаграмма по часам.

## Поля

На этом экране нет формы — только карточки для просмотра:

| Карточка | Что показывает |
|---|---|
| Строка KPI | **Активные звонки**, **Всего сегодня**, **Отвечено**, **Пропущено**, **Среднее ожидание** |
| **Почасовой объём** | Входящие/исходящие/пропущенные звонки за сегодня — диаграмма по часам |
| Состояние системы | Asterisk, База данных, Диск, состояние каждого транка (ссылка **Подробнее** — на страницу Состояния системы) |
| **Текущие звонки** | Звонки, идущие прямо сейчас — от кого, кому, направление, длительность |
| **Очереди** | По каждой очереди: количество операторов онлайн, количество ожидающих, максимальное время ожидания |
| **Пропущенные звонки** | Время, от кого, на какой DID, отметка перезвонили/не перезвонили, ссылка для обратного звонка |
| **Парковка вызовов** | Звонки, находящиеся сейчас на парковке — номер слота, кто поставил, с какого времени |

## Как это делается

### Поиск проблемы и переход в соответствующий раздел
1. Посмотрите на список оповещений в верхней части страницы — в каждой строке указано, к какой проблеме
   она относится.
2. Нажмите кнопку **Открыть**, чтобы перейти в проблемный раздел (например при разрыве связи с транком —
   откроется страница Транков).
3. Если на карточке Состояния системы виден красный значок, перейдите по ссылке **Подробнее** на страницу
   Состояния системы для полной диагностики.

### Обратный звонок по пропущенному звонку
1. На карточке **Пропущенные звонки** найдите нужную строку.
2. Если строка помечена **Не перезвонили** — нажмите ссылку **Перезвонить** (номер набирается через
   браузер/системное телефонное приложение).

## Советы и ограничения

> [!TIP]
> Все карточки обновляются автоматически — перезагружать страницу не нужно.

> [!WARNING]
> Карточка **Парковка вызовов** видна только пользователям с правом `apps:view`. У роли оператора этого
> права нет, поэтому на панели оператора эта карточка вообще не появляется — это не ошибка.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Сообщение «Не удалось загрузить.» | Проблема сети/API между панелью и сервером | Нажмите **Повторить**; если не помогает, проверьте сетевое соединение |
| Красный значок в строке транка | Транк не зарегистрирован или нет связи | Проверьте состояние транка в разделе [Транки](/docs/trunks) |
| «Процесс Asterisk не отвечает» | Служба Asterisk не работает или перегружена | Обратитесь к администратору сервера/на страницу [Состояние системы](/docs/status) |
| Красный/жёлтый значок в строке диска | Свободное место на диске уменьшилось | Очистите старые записи/резервные копии или увеличьте диск |
