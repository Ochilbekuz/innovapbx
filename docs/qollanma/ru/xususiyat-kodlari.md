# Коды функций (полный список)

Полный список всех стандартных `*`-кодов, используемых во внутреннем номере Innova PBX путём набора на
клавиатуре телефона — в качестве быстрого справочника. Изменение самих кодов выполняется на странице
[Коды функций](/docs/featurecodes).

## Список стандартных кодов

| Функция | Стандартный код | Комментарий |
|---|---|---|
| Своя голосовая почта | `*97` | Вход в голосовую почту |
| Голосовая почта другого внутреннего номера | `*98` | Оставить сообщение в чужой голосовой почте |
| Переключение DND | `*76` | Включение/отключение режима «Не беспокоить» |
| Постоянная переадресация — включение | `*72` | Безусловная переадресация звонков |
| Постоянная переадресация — отключение | `*73` | |
| Переадресация при занятости — включение | `*90` | |
| Переадресация при занятости — отключение | `*91` | |
| Перехват по группе | `*8` | Приём звонка в звонящей группе |
| Прямой перехват | `**` + внутренний номер | Приём звонка на конкретном внутреннем номере |
| Парковка | `*70` | Постановка звонка на «парковку» |
| Эхо-тест | `*43` | Проверка качества звука |
| Говорящие часы | `*60` | Голосовое сообщение о времени |
| Включение/отключение Follow Me | `*21` | Переключение функции «Следовать за мной» |
| Вход/выход из очереди | `*45` | Вход/выход оператора очереди (обычно управляется из раздела Очереди) |
| Переключение паузы | `*46` | Пауза оператора очереди (обычно управляется из раздела Очереди) |
| Интерком (внутренний быстрый вызов) | `*80` + внутренний номер | |
| Ожидание звонка — включение | `*56` | Call waiting |
| Ожидание звонка — отключение | `*57` | |

## Правило формата

Каждый код начинается с `*`, после которого следует 1–6 символов (цифры, `*` или `#`): `^\*[0-9*#]{1,6}$`.

## Правило конфликтов (clash)

Двум функциям нельзя назначить одинаковый код **или** код, являющийся **префиксом** другого — например
`*7` и `*72` не могут существовать одновременно, так как Asterisk не может надёжно определить, к какому
из них относится набираемый номер. В этом случае система отказывает в сохранении и выдаёт ошибку «Этот
код конфликтует с другой функцией».

> [!NOTE]
> Код переключения режима День/Ночь (`*28<код>`) — это отдельный механизм, он не отображается в таблице
> [Кодов функций](/docs/featurecodes), а настраивается для каждого временного условия (time condition)
> в разделе [День/Ночь](/docs/day_night).
