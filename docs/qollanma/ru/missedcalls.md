# Уведомление о пропущенном звонке

Этот раздел мгновенно уведомляет нужных людей о пропущенных звонках через **Telegram** или **E-mail**.
Например: можно создать правило — обо всех пропущенных звонках на любой DID-номер отправлять уведомление
в Telegram-чат менеджера.

## Где находится

Меню: **Приложения → Уведомление о пропущенном звонке**. Кто видит: пользователи с правом `apps`
редактируют, остальные только просматривают.

## Основные понятия

- **Правило** — определяет, о каких звонках (охват) и кому (получатели) отправлять уведомление.
- **Охват** — к каким звонкам относится правило: **Все**, определённый **DID**, **Очередь**,
  **Группа** или **Внутренний номер**.
- **Включая внутренние звонки** — если отключено, уведомления приходят только о пропущенных звонках
  извне; если включено, учитываются и пропущенные звонки между внутренними номерами.
- **Получатели** — Telegram chat ID и/или E-mail адреса; в одном правиле их может быть несколько.
- **Журнал уведомлений** — история каждого отправленного (или неотправленного) уведомления: статус
  (в очереди/отправлено/неуспешно), количество попыток и текст ошибки.

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Название | Название правила | Обязательно, не более 128 символов |
| Тип охвата | К каким звонкам относится | Все / DID / Очередь / Группа / Внутренний номер |
| Значение | Если тип охвата отличается от «Все» — конкретный DID/очередь/группа/внутренний номер | Например для DID `998712345678` |
| Включая внутренние звонки | Учитывать ли внутренние пропущенные звонки | По умолчанию — отключено |
| Telegram chat ID | Чат(ы), куда отправляется уведомление | Например `-100123456789` |
| E-mail | Email-адрес(а), куда отправляется уведомление | Например `name@company.uz` |
| Включено | Активно правило или временно приостановлено | По умолчанию — включено |

## Как это делается

### Создание нового правила
1. Нажмите **Новое правило**, введите название.
2. Выберите **Тип охвата**; если он отличается от «Все» — укажите соответствующее значение
   (DID/очередь/группа/внутренний номер).
3. При необходимости включите **Включая внутренние звонки**.
4. Добавьте один или несколько **Telegram chat ID** и/или **E-mail**.
5. Нажмите **Добавить**.

### Проверка правила
1. В строке правила нажмите значок проверки (кнопка теста) — всем получателям будет отправлено тестовое
   уведомление.
2. Результат появится во всплывающем сообщении: успешно или с текстом ошибки.

### Временное отключение правила
1. Откройте правило на редактирование, отключите **Включено**, нажмите **Сохранить** — правило не
   работает, но остаётся сохранённым.

### Просмотр журнала уведомлений
1. Перейдите на вкладку **Журнал уведомлений** — отображается время, правило, информация о звонке,
   статус, количество попыток и (при неудаче) текст ошибки каждого отправленного уведомления.

### Удаление
1. Нажмите значок корзины в конце строки, подтвердите.

> [!TIP]
> Сначала проверьте кнопкой **Проверить**, что Telegram/E-mail настроены правильно — не полагайтесь на
> то, что настройка «работала раньше».

> [!WARNING]
> Один звонок может подходить под несколько правил одновременно (например «Все» и конкретное правило
> «Очередь») — в этом случае уведомление отправляется отдельно по **каждому подходящему правилу**, и
> оно может повториться.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Уведомление не приходит | Правило отключено или охват не совпадает | Переведите правило в состояние **Включено**, проверьте охват |
| Уведомление не доходит в Telegram | Неверный chat ID или бот не добавлен в группу | Проверьте chat ID, добавьте бота в группу, подтвердите кнопкой **Проверить** |
| E-mail не приходит | Неверный адрес или не настроен SMTP | Проверьте настройки SMTP в [Интеграциях](/docs/integrations) |
| В журнале много статусов «Неуспешно» | Адрес получателя/чат недействителен | Прочитайте текст ошибки и исправьте получателя |
