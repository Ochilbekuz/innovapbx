# Установка

Innova PBX устанавливается двумя способами — полностью автоматически через готовый **ISO**, либо
**скриптом** на существующий Linux-сервер; результат в обоих случаях одинаков: папка `/opt/innova`,
systemd-служба `innova-pbx` и автоматически сгенерированные секретные ключи.

## Основные понятия

- **Требования**: 64-битный (x86-64) сервер, минимум 2 ядра, 4 ГБ RAM, 20 ГБ+ диска (для ISO — 32 ГБ+).
- **Asterisk работает в режиме host-сети** — для SIP/RTP нет NAT, поэтому трафик приходит прямо на IP
  сервера.
- **ISO** — на основе Debian 13 (trixie), устанавливается даже без подключения к интернету, диск
  полностью отводится серверу.
- **Скрипт (`install.sh`)** — ставится на Debian 12/13, Ubuntu 22.04/24.04, требует интернет (собирает
  или загружает образы Docker), не затрагивает другие службы на сервере (нужно только, чтобы были
  свободны необходимые порты).
- В обоих способах в конце в консоли выводится одноразовый **код установки** — этот код запрашивается
  при создании учётной записи администратора на этапе [Первая настройка](/docs/birinchi-sozlash).

## Как это делается

### Установка через ISO
1. Скачайте файл ISO и запишите его на USB-флешку (командой `dd`, Rufus или Etcher — «режим DD») либо
   подключите как CD в виртуальной машине.
2. Загрузите сервер с этого внешнего диска. Первый пункт в меню загрузки — **«Innova PBX — автоматическая
   установка»** — запускается сам через 10 секунд (работает и в BIOS, и в UEFI).
3. Будет задан только один вопрос: пароль для пользователя `innova` (понадобится позже для входа по SSH
   и в консоль). Если DHCP не найден, также запрашиваются сетевые настройки (IP, маска, gateway, DNS).
4. После завершения установки сервер автоматически перезагружается; первый запуск занимает 2–5 минут
   (загружаются образы Docker).
5. Откройте с другого компьютера в браузере адрес `http://<IP-сервера>/`, показанный в консоли —
   откроется страница создания администратора ([Первая настройка](/docs/birinchi-sozlash)).

> [!WARNING]
> В процессе установки **первый найденный диск, кроме выбранного, полностью очищается** (создаётся LVM
> в одну партицию). Если на сервере есть другой диск с данными, которые нужно сохранить, отключите его
> перед установкой.

### Установка скриптом (на существующий сервер)
1. Войдите на сервер с правами **root**, разместите на сервере файлы проекта (репозиторий).
2. Запустите следующую команду:
   ```
   sudo ./install.sh
   ```
3. Скрипт сначала проверяет необходимые порты (80, 443, 5060, 5061, 5038, 8088, 5432, 8710) — если
   какой-то из них занят (например старым FreePBX/Asterisk, другим веб-сервером или Postgres),
   останавливается с ошибкой.
4. Если Docker не установлен, он устанавливается автоматически (Debian 13 — из официального репозитория
   Debian; Debian 12/Ubuntu — с `download.docker.com`; если compose 2.24+ уже есть, этот шаг
   пропускается).
5. Файлы размещаются в `/opt/innova`, создаётся и запускается systemd-служба `innova-pbx`.
6. По готовности в консоли выводится сообщение `TAYYOR: http://<IP-сервера>/` и одноразовый **код
   установки**.

### Дополнительные параметры (только для способа со скриптом)
1. `--web-port 8080` — для использования другого порта, если 80-й занят (применяется только при первой
   установке, позже изменить нельзя).
2. `--images images.tar.zst` — установка с готовым файлом образов Docker (без интернета или быстрее;
   файл `innova/images.tar.zst` внутри ISO или заранее подготовленный командой `docker save ... |
   zstd`).
3. `--version V` — установка конкретной версии (по умолчанию используется версия из файла `VERSION` в
   проекте).

### Последующее обновление
1. Войдите на сервер и запустите:
   ```
   innova-update
   ```
   Это загружает самую свежую версию с GitHub, предварительно сохраняет резервную копию базы в папку
   `/opt/innova/backups/`, файл `.env` / база / веб-порт остаются без изменений.
2. Только проверить наличие новой версии: `innova-update --check`.
3. Обновление с готовым файлом образов: `innova-update --images ФАЙЛ`.
4. Переустановка даже если версия показана как «не новая» (для исправления повреждённого состояния):
   `innova-update --force`.

> [!NOTE]
> В системах, установленных до версии 1.0.1, `innova-update` отсутствует — нужно один раз вручную
> выполнить `git pull && ./install.sh`, после этого `innova-update` начнёт работать.

## Советы и ограничения

> [!WARNING]
> Перед установкой остановите другие службы, занимающие порты 80, 5060, 5061, 5038, 8088, 5432, 8710
> (старый FreePBX/Asterisk, веб-сервер, Postgres) — иначе скрипт остановится именно на этом шаге.

> [!TIP]
> Рекомендуется задать серверу статический IP — если IP изменится из-за DHCP, SIP-устройства могут
> потерять соединение.

> [!WARNING]
> Браузерный софтфон (WebRTC) требует **HTTPS** для доступа к микрофону — через обычный `http://IP-сервера`
> не работает. Настольные телефоны и мобильные SIP-приложения при этом работают без проблем.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Ошибка «порты заняты» | Другой PBX/веб-сервер/Postgres занял эти порты | Остановите соответствующую службу или используйте `--web-port` для веб-порта |
| Служба `innova-pbx` не запустилась | Ошибка контейнера Docker | Проверьте причину командами `journalctl -u innova-pbx -n 30` и `docker ps` |
| Веб-панель долго не открывается | Долго загружаются образы или произошла ошибка | Проверьте логи указанными командами, затем попробуйте снова |
| Браузерный софтфон не работает | На сервере нет HTTPS | Настройте HTTPS (сертификат) для сервера или используйте настольный телефон/SIP-приложение |
