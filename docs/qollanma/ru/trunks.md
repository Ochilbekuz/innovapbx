# Транки

Транк — это SIP-соединение между вашей Innova PBX и телефонным оператором (или другой АТС); через него
уходят исходящие и приходят входящие звонки из внешнего мира. В этом разделе можно добавлять, настраивать,
отслеживать состояние связи и проверять транки.

## Где находится

Меню: **Подключение → Транки**. Кто видит: право `connect:view`. Добавление/редактирование/удаление —
право `connect:edit`; при его отсутствии на странице показывается подсказка **«У вас нет прав на
управление транками — доступны только просмотр и проверка»** (проверка работает и с правом только на
просмотр).

## Основные понятия

- **Способ аутентификации**:
  - **По IP (CIDR)** — проверяет, что пакеты от оператора приходят из указанной сети (сетей), логин/пароль
    не нужны.
  - **Регистрация (логин/пароль)** — Innova PBX регистрируется у оператора по логину/паролю (классическая
    SIP-регистрация).
- **Состояние связи** — **Работает**, **Нет связи**, **Не проверено**, **Отключён**; в режиме регистрации
  дополнительно отметка **Зарегистрирован** / **отклонена** / **ожидание**.
- **Проверка** — сразу отправляет транку тестовый запрос и показывает, есть ли связь и время ответа.

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| **Имя** | Название для распознавания транка | — (обязательно) |
| **Хост** | IP или домен оператора | `sip.operator.uz` (обязательно) |
| **Порт** | SIP-порт | в диапазоне 1–65535, по умолчанию 5060 |
| **Способ аутентификации** | **По IP (CIDR)** или **Регистрация (логин/пароль)** | — |
| **Приём (match CIDR)** | *(только в режиме IP)* Из каких сетей пришедший пакет считается относящимся к этому транку | По одной CIDR в строке, например `203.0.113.0/24` |
| **Логин** / **Пароль** | *(только в режиме регистрации)* Учётные данные, выданные оператором | Если не менять пароль, оставьте поле пустым — текущий сохранится |
| **From domain** | *(только в режиме регистрации)* Домен/хост для регистрации | `sip.operator.uz` |
| **Исходящий Caller ID** | Номер, показываемый при исходящих звонках через этот транк | необязательно, например `+998712000000` |
| **Кодеки** | Какие аудиокодеки используются | `ulaw`, `alaw`, `g722`, `opus` — нужно выбрать хотя бы один |
| **Макс. каналов** | Сколько звонков может идти через этот транк одновременно | пусто — без ограничения |
| **Включён** | Временное отключение транка | по умолчанию включён |

## Как это делается

### Добавление нового транка (по IP)
1. Нажмите кнопку **Новый транк**.
2. Введите **Имя**, **Хост**, **Порт**, в поле **Способ аутентификации** выберите **По IP (CIDR)**.
3. В поле **Приём (match CIDR)** укажите сеть оператора.
4. Отметьте нужные **Кодеки**, при необходимости заполните **Исходящий Caller ID** и **Макс. каналов**.
5. Нажмите **Добавить**.

### Добавление нового транка (через регистрацию)
1. Нажмите **Новый транк**, в поле **Способ аутентификации** выберите **Регистрация (логин/пароль)**.
2. Заполните поля **Логин**, **Пароль**, **From domain**.
3. Выберите кодеки, нажмите **Добавить**.

### Проверка транка
1. В таблице в строке нужного транка нажмите значок разъёма (plug).
2. В открывшемся окне появится результат **Успешно**/**Неуспешно** и время ответа (мс).

### Удаление транка
1. В строке нажмите значок **Удалить**.
2. Прочитайте предупреждение — связь (исходящая/входящая) через этот транк прекратится немедленно — и
   подтвердите.

## Советы и ограничения

> [!WARNING]
> Удаление транка применяется немедленно — если транк используется в исходящих маршрутах, эти
> направления перестанут работать. Перед удалением проверьте в разделе [Исходящие маршруты](/docs/outbound),
> какие маршруты используют этот транк.

> [!TIP]
> Если менять пароль не нужно, оставьте поле **Пароль** пустым — текущий пароль останется без изменений.

> [!TIP]
> Нужно выбрать хотя бы один кодек; выбор кодека, который не поддерживает оператор, может ухудшить
> качество звонка.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| «Неверный хост» | Поле хоста не в формате IP или домена | Введите корректный IP/домен |
| «"..." не является корректным CIDR» | Строка в поле **Приём** не в формате CIDR | Укажите в формате `203.0.113.0/24` |
| «В режиме регистрации нужен пароль» | В режиме регистрации не введён пароль (и у транка ещё не сохранён пароль) | Заполните поле пароля |
| Состояние **Нет связи** | Серверы оператора не отвечают или проблема с сетью | Проверьте правильность хоста/порта, выполните диагностику кнопкой **Проверить** |
| **Регистрация отклонена** | Неверный логин/пароль или блокировка оператором | Проверьте логин/пароль с оператором и введите заново |
