# Режим День/Ночь

**Режим День/Ночь** похож на [условие рабочего времени](/docs/timegroups), но переключается не по
графику, а вручную (кодом с телефона или кнопкой в панели) — простой выключатель «открыто/закрыто».
Например: вечером, уходя, сотрудник ресепшн набирает `*28<код>`, и все звонки переходят на ночного
дежурного.

## Где находится

Меню: **Маршрутизация → Кун/Тун**. Кто видит: пользователи с правом `routing` редактируют, остальные
только просматривают.

## Основные понятия

- **Состояние (mode)** — правило всегда находится в одном из двух состояний: **Дневное** или **Ночное**.
  Не связано с графиком — переключается только вручную.
- **Код функции** — каждому правилу привязывается одна цифра, набрав с телефона `*28<код>` можно
  переключить состояние (например при коде правила `1` — `*281`).
- **PIN** — необязательно, 4–8 цифр. Если задан, перед переключением состояния по телефону запрашивается
  PIN.
- **Индикатор BLF** — если на SIP-телефоне кнопка BLF настроена с кодом `Custom:DAYNIGHT<код>`, индикатор
  показывает текущее состояние (дневное/ночное) и переключает его при нажатии.
- При переключении состояния через панель PIN не запрашивается — PIN действует только при переключении
  телефонным кодом.

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Имя | Название правила | Не более 128 символов |
| Код функции | Цифра после `*28` | Одна цифра `0-9` |
| Дневной адрес | Куда идёт звонок при состоянии «дневное» | Обязательно |
| Ночной адрес | Куда идёт звонок при состоянии «ночное» | Обязательно |
| PIN | Пароль, запрашиваемый перед переключением состояния | Необязательно, 4–8 цифр |

## Как это делается

### Добавление нового правила
1. Нажмите **Добавить правило**, введите имя и код функции (одна цифра).
2. Выберите **Дневной адрес** и **Ночной адрес**.
3. При необходимости задайте PIN.
4. Нажмите **Добавить** — новое правило по умолчанию начинается в состоянии **Дневное**.

### Переключение состояния через панель
1. В таблице в строке правила нажмите значок луны/солнца — состояние сразу переключится **Дневное** ↔
   **Ночное**.

### Переключение состояния с телефона
1. На телефоне наберите `*28<код>` (например `*281`).
2. Если задан PIN, введите его по запросу.

### Настройка индикатора BLF
1. В настройках SIP-телефона/sip.js на кнопку BLF введите код `Custom:DAYNIGHT<код>` — индикатор будет
   показывать текущее состояние и переключать его при нажатии.

### Удаление PIN
1. Откройте правило на редактирование, отметьте **Удалить PIN**, нажмите **Сохранить**.

### Удаление
1. Нажмите значок корзины в конце строки.
2. Если правило используется где-то ещё, удаление блокируется — сначала удалите эти связи.
3. Звонки, направленные на удалённое правило, теперь услышат сигнал «нет ответа».

> [!TIP]
> Режим День/Ночь удобен для быстрого переключения одной кнопкой/кодом; если нужен автоматический
> еженедельный график, лучше подходит условие [Рабочее время](/docs/timegroups).

> [!WARNING]
> Состояние не возвращается автоматически — правило, переведённое в «Ночное», останется в этом состоянии,
> пока утром вы сами (кодом или через панель) не вернёте его в «Дневное».

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| `*28<код>` не работает | Код набран неверно или введён неправильный PIN | Проверьте точный код правила и PIN |
| Индикатор BLF не загорается | На телефоне неверно настроен `Custom:DAYNIGHT<код>` | Проверьте, что код соответствует коду функции в правиле |
| Не удаётся удалить правило | Используется во входящем маршруте или другом адресе | Сначала удалите эти связи |
