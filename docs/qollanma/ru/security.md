# Безопасность

Здесь настраивается защита PBX-сервера от атак через SIP извне (повторные попытки с неверным паролем,
звонки на международные номера через скомпрометированную учётную запись — «toll fraud»). Сколько было
попыток атак за последние 24 часа, какие IP блокированы и нужна ли обязательная 2FA для всех — всё на
одном экране.

## Где находится

Меню: **Система → Безопасность**. Кто видит: любой может просматривать, но изменять настройки,
блокировать/разблокировать IP может только пользователь с правами `*` (полный администратор).

## Основные понятия

- **Защита от SIP-атак** — работает в стиле fail2ban: если за установленное **окно** времени (в
  секундах) с одного IP происходит больше установленного числа **неудачных попыток**, этот IP
  автоматически **блокируется**.
- **Доверенные сети** — IP-адреса из этих CIDR никогда не блокируются автоматически (`127.0.0.0/8`
  всегда доверенный).
- **Считать локальную сеть доверенной** — при включении офисные телефоны (192.168.x.x, 10.x.x.x,
  172.16–31.x.x) не блокируются сколько бы раз ни ошиблись при вводе логина, но попытки видны в
  статистике.
- **Лимиты toll-fraud** — ограничивают, сколько исходящих (включая международные) звонков может
  совершить внутренний номер за час/день; при превышении лимита номер блокируется автоматически.
- **Политика 2FA** — для кого обязательна двухфакторная аутентификация (через приложение TOTP): ни для
  кого, только для администраторов, или для всех пользователей.

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| **Защита от SIP-атак** → Включено | Включает/отключает защиту | — |
| Максимум неудачных попыток | При превышении блокирует | — |
| Окно (секунды) | Попытки считаются в этом временном окне | — |
| Срок блокировки (секунды) | `0` — блокирует бессрочно, до ручной разблокировки | — |
| Доверенные сети (CIDR) | По одной в строке, никогда не блокируются | `127.0.0.0/8` всегда |
| Не блокировать локальную сеть автоматически | При включении — локальные IP не блокируются | — |
| **Toll-fraud** → Включено | Включает/отключает лимиты | — |
| Одновременные исходящие вызовы | `0` — без ограничения | — |
| Исходящих в час на номер | Часовой лимит | — |
| Международных в день на номер | Дневной лимит международных звонков | — |
| **2FA** → Для кого обязательна | Не обязательна / Только администраторы / Все пользователи | По умолчанию: Не обязательна |

## Как это делается

### Просмотр последних попыток атак
1. На вкладке **Состояние** посмотрите число неудачных/блокированных попыток за последние 24 часа и
   часовой график.
2. В списке **IP с наибольшим числом попыток** найдите подозрительный IP и при необходимости нажмите
   кнопку **Блокировать**.

### Блокировка IP вручную
1. На вкладке **Блокированные IP** нажмите **Блокировать IP**.
2. Введите IP-адрес, при желании укажите комментарий.
3. **Срок (секунды)** — значение `0` блокирует бессрочно, иначе через указанное число секунд блокировка
   снимается автоматически.
4. Подтвердите кнопкой **Блокировать**.

### Разблокировка IP
1. На вкладке **Блокированные IP** в нужной строке нажмите **Разблокировать**.

### Настройка защиты от SIP-атак и лимитов toll-fraud
1. Откройте вкладку **Настройки**.
2. В блоке **Защита от SIP-атак** укажите включение, лимиты и доверенные сети.
3. В блоке **Лимиты toll-fraud** введите лимиты исходящих звонков.
4. Нажмите **Сохранить**.

### Разблокировка внутреннего номера, заблокированного из-за toll-fraud
1. На вкладке **Toll-fraud** найдите блокированный внутренний номер и нажмите **Разблокировать**.

### Настройка политики 2FA
1. На вкладке **Настройки** в блоке **Двухфакторная аутентификация (2FA)** выберите **Для кого
   обязательна**.
2. Нажмите **Сохранить** — выбранная группа при следующем входе обязана подключиться через приложение
   TOTP.

### Просмотр событий безопасности
1. На вкладке **События** отфильтруйте историю по типу (IP блокирован, разблокирован, toll-fraud и
   т.д.).

## Советы и ограничения

> [!WARNING]
> Если считать локальную сеть доверенной, скомпрометированное/заражённое устройство внутри офиса также
> сможет совершать попытки без ограничений — используйте только в по-настоящему доверенной офисной
> сети.

> [!TIP]
> Если вы подключаетесь к панели управления со своего статического IP, добавьте его в **Доверенные
> сети** — чтобы случайно не заблокировать самого себя.

- Если срок блокировки равен `0`, IP остаётся блокированным, пока его не разблокируют вручную.
- Установка политики 2FA на «Все пользователи» означает, что все при следующем входе обязаны подключить
  приложение TOTP (для случая утери устройства 2FA — см. [Проблемы](/docs/muammolar)).

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Мой IP заблокирован | Защита от SIP-атак посчитала неверные попытки входа атакой | Администратор снимает блокировку на вкладке **Блокированные IP**; затем добавьте IP в **Доверенные сети** |
| Внутренний номер не может звонить, причина «toll-fraud» | Превышен часовой/дневной лимит | Разблокируйте на вкладке **Toll-fraud**, при необходимости увеличьте лимит в **Настройках** |
| «Неверный IP-адрес» | Формат CIDR/IP введён с ошибкой | Введите в правильном формате, например `203.0.113.9` |
| Утеряно устройство 2FA | Пользователь не может войти в приложение TOTP | См. пункт «Утеря устройства 2FA» в разделе [Проблемы](/docs/muammolar) |
