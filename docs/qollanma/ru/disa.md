# DISA

**DISA** (Direct Inward System Access) позволяет сотруднику, находящемуся вне офиса, позвонить со своего
телефона на офисный номер, ввести PIN-код и совершать **исходящие звонки на внешние номера** так, будто
он звонит с офисного телефона. Например: сотрудник в поездке звонит на офисный номер, вводит PIN, после
чего набирает любой внешний номер и разговаривает через офисный транк.

## Где находится

Меню: **Приложения → DISA**. Кто видит: пользователи с правом `apps` редактируют, остальные только
просматривают.

## Основные понятия

- **DISA** — набор настроек (выбирается как адрес во [входящем маршруте](/docs/inbound) или в IVR); когда
  внешний звонящий попадает на этот адрес, у него запрашивается PIN.
- **PIN** — пароль для входа (4–8 цифр); хранится в необратимом (HMAC) виде — при редактировании не
  отображается, можно только задать новый PIN или убрать его.
- **Разрешить вход без PIN** — при включении вход возможен и без ввода PIN; рекомендуется **только для
  доверенных транков** — если PIN оставлен пустым, этот параметр обязательно должен быть включён.
- **Подмена CID** — заменяет номер, отображаемый при исходящих звонках через DISA.
- **Лимит попыток** — при вводе неверного PIN указанное число раз звонок автоматически завершается.
- DISA открывает доступ только к **исходящим маршрутам** — пути к внутренним кодам функций нет.

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Название | Название настройки DISA | Обязательно, не более 128 символов |
| PIN | Пароль для входа | 4–8 цифр; пустое значение возможно только при включённом «Входе без PIN» |
| Разрешить вход без PIN | Вход без запроса PIN | По умолчанию — отключено |
| Подмена CID | Номер, отображаемый при исходящем звонке | Необязательно |
| Время ожидания ввода цифры (сек) | Пауза между цифрами | 1–60, по умолчанию `5` |
| Время ожидания ответа (сек) | Общее время на ввод PIN/номера | 1–60, по умолчанию `10` |
| Максимум попыток | После скольких неверных PIN звонок завершается | 1–10, по умолчанию `3` |
| Включено | DISA активна или временно отключена | По умолчанию — включено |

## Как это делается

### Создание новой DISA
1. Нажмите **Новая DISA**, введите название.
2. Введите PIN (4–8 цифр) или включите **Разрешить вход без PIN** и оставьте PIN пустым.
3. При необходимости измените подмену CID и настройки времени/попыток.
4. Нажмите **Добавить**.

### Подключение DISA к входящему маршруту
1. На странице [Входящих маршрутов](/docs/inbound) или IVR выберите эту DISA как адрес.
2. Теперь все, кто звонит на этот DID/кнопку IVR снаружи, проходят через DISA.

### Замена/удаление PIN
1. Откройте DISA для редактирования, введите новое значение в поле **PIN** (старый PIN не отображается).
2. Для работы без PIN отметьте **удаление PIN** и включите **Разрешить вход без PIN**.
3. Нажмите **Сохранить**.

### Временное отключение
1. Откройте DISA для редактирования, отключите **Включено**, нажмите **Сохранить** — DISA перестаёт
   работать, но остаётся сохранённой.

### Удаление
1. Нажмите значок корзины в конце строки.
2. Если DISA используется в другом месте (маршрут, IVR), удаление блокируется — сначала удалите эти
   связи; после удаления звонки, направленные на неё, услышат сигнал занятости.

> [!WARNING]
> Включайте **Разрешить вход без PIN** только на доверенных, контролируемых транках — иначе кто угодно,
> позвонив на офисный номер, сможет совершать бесплатные внешние звонки (toll fraud).

> [!TIP]
> Установите небольшое значение **Максимум попыток** (например 3) — это затруднит подбор PIN методом
> перебора.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Ошибка «PIN boʻsh boʻlishi uchun allow_no_pin=true shart» | PIN оставлен пустым, но «Вход без PIN» не включён | Введите PIN или включите «Разрешить вход без PIN» |
| DISA не подключает к исходящему звонку | Исходящие маршруты не настроены или транк занят | Проверьте [Исходящие маршруты](/docs/outbound) |
| При неверном PIN звонок завершился быстрее ожидаемого | Установлен небольшой **Максимум попыток** | Увеличьте число попыток в настройках |
| Не удаётся удалить DISA | Используется в маршруте/IVR | Сначала удалите эти связи |
