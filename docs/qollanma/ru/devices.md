# Телефонные аппараты

Этот раздел предназначен для автоматической настройки физических IP-телефонов (Yealink, Grandstream,
Fanvil и других) по сети: при включении аппарат сам загружает свою конфигурацию, ручная настройка не
требуется.

## Где находится

Меню: **Пользователи → Телефонные аппараты**. Кто видит: право `extensions:view`. Полное управление
(добавление/редактирование/удаление/кнопки/повторная настройка) — право `extensions:edit`; при его
отсутствии в верхней части страницы показывается баннер **«Только просмотр — для изменения этого раздела
нужны права администратора»**.

## Основные понятия

- **Провизионинг** — загрузка аппаратом собственного файла настроек по сети (автоматически через DHCP
  option 66 или по вручную указанному адресу).
- **Обнаруженные устройства** — аппараты, от которых пришёл запрос провизионинга с MAC-адресом,
  отсутствующим в списке; можно привязать к внутреннему номеру или проигнорировать.
- **Программируемые кнопки (BLF/быстрый набор)** — назначение кнопкам аппарата отображения статуса
  коллеги (BLF), быстрого набора, линии, парковки или функции DND; количество зависит от модели.
- На экране три вкладки: **Аппараты**, **Настройки**, **Журнал**.

## Поля

**Таблица «Аппараты»:**

| Столбец | Что показывает |
|---|---|
| **Статус** | **Не запрашивал**, **Настроен**, **В списке**, **Требует обновления** |
| **MAC** | MAC-адрес аппарата |
| **Производитель / модель** | Например Yealink T46S |
| **Внутренний номер** | Привязанный номер или **Не привязан** |
| **IP** | Последний известный IP |
| **Firmware** | Версия firmware аппарата |
| **Последнее обращение** | Время последнего запроса |

**Форма добавления/редактирования аппарата:**

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| **MAC-адрес** | 12 hex-символов (можно вводить с `:`/`-`); после добавления не меняется | — |
| **Производитель** | Производитель аппарата | Yealink / Grandstream / Fanvil |
| **Модель** | Список моделей, соответствующих выбранному производителю | — |
| **Внутренний номер** | К какому номеру подключается | **К номеру с включённым браузерным софтфоном (WebRTC) аппарат подключить нельзя** |
| **Метка** | Необязательно, отображается в таблице и конфигурации | «Приёмная» |
| **Включён** | Отключённый аппарат не получает конфигурацию | по умолчанию: включён |

## Как это делается

### Добавление нового аппарата вручную
1. На вкладке **Аппараты** нажмите кнопку **Добавить аппарат**.
2. Введите **MAC-адрес**, **Производителя**, **Модель** и **Внутренний номер**.
3. При желании укажите **Метку**, нажмите кнопку **Сохранить**.

### Привязка обнаруженного устройства
1. Если аппарат подключился к сети, но ещё не оформлен, он отображается в разделе **«Обнаруженные
   устройства»**.
2. В нужной строке нажмите **Привязать к номеру**.
3. Выберите **Внутренний номер** и **Модель**, при желании укажите **Метку** и подтвердите.
4. Если не нужно, отклоните строку кнопкой **Игнорировать**.

### Настройка программируемых кнопок
1. В строке нужного аппарата нажмите значок **Кнопки**.
2. Для каждой строки выберите тип (**BLF (коллега)**, **Быстрый набор**, **Линия**, **Парковка**, **DND**,
   **Пусто**), введите значение и метку.
3. Не превышая число кнопок, разрешённых моделью, добавляйте строки кнопкой **Добавить кнопку**, нажмите
   **Сохранить**.

### Просмотр и повторная настройка конфигурации
1. В строке нажмите значок **Config**, чтобы увидеть текущий файл настроек (пароли скрыты символами
   `***`).
2. Если аппарат работает со старыми настройками — нажмите кнопку **Повторная настройка**, аппарату будет
   отправлен запрос на получение новой конфигурации.

### Замена токена провизионинга
1. В карточке **Адрес провизионинга** над вкладкой **Аппараты** нажмите **Заменить токен**.
2. Прочитайте предупреждение и подтвердите — старый адрес сразу перестаёт работать, на все аппараты
   новый адрес нужно будет ввести вручную либо он обновится автоматически через DHCP.

## Советы и ограничения

> [!TIP]
> Если на вашем DHCP-сервере настроен **option 66** с адресом URL провизионинга, новые аппараты будут
> включаться в работу автоматически без какой-либо ручной настройки.

> [!WARNING]
> К внутреннему номеру с включённым **браузерным софтфоном (WebRTC)** нельзя подключить физический
> аппарат — они не работают одновременно на одном номере.

> [!WARNING]
> После замены токена провизионинга на всех аппаратах, не получивших адрес через DHCP, нужно будет
> вручную ввести новый URL — иначе они не смогут получить новую конфигурацию.

> [!NOTE]
> Если к одному внутреннему номеру привязано несколько аппаратов, при прямых звонках звонят все
> одновременно. При звонке через участника очереди, вызове по API и в группах громкой связи звонит
> только один аппарат — это ограничение Asterisk `Page()`.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| «Неизвестный MAC» (в журнале) | Отсутствующий в списке аппарат отправил запрос провизионинга | Привяжите его в разделе «Обнаруженные устройства» |
| «Неверный токен» | На аппарате остался старый адрес провизионинга | Введите вручную новый URL/адрес DHCP на аппарат |
| «Сеть отклонена» | IP-адрес аппарата не входит в список разрешённых сетей на вкладке **Настройки** | Добавьте сеть аппарата в **Разрешённые сети (CIDR)** на вкладке Настройки |
| Статус **Требует обновления** | Конфигурация аппарата изменилась, но он её ещё не получил | Нажмите **Повторная настройка** или перезагрузите аппарат |
| «Превышен лимит» (в журнале) | От одного аппарата поступают слишком частые запросы | Подождите и повторите попытку; если продолжается — проверьте настройки сети/аппарата |
