# Первоначальная настройка

После завершения установки при первом открытии веб-панели автоматически появляется страница настройки из
двух шагов: создание учётной записи администратора и ввод сетевых настроек. Эта страница открывается
только **один раз** — после создания администратора она закрывается навсегда и повторно открыть её
нельзя.

## Основные понятия

- **Код установки** — код, который однократно выводится в консоли/терминале по завершении процесса
  [Установки](/docs/ornatish); нужен только на этой странице, только один раз.
- Страница состоит из двух шагов: **1. Администратор** и **2. Язык и сеть**.
- После второго шага отдельного этапа «Apply Config» нет — каждое изменение вступает в силу немедленно.

## Поля

**Шаг 1 — Администратор**:

| Поле | Что делает | Требование |
|---|---|---|
| **Код установки** | Одноразовый код, выведенный в консоли при установке | Обязательно, должен быть введён верный код |
| **Логин** | Имя для входа администратора в систему | Не менее 3 символов |
| **Полное имя** | Имя и фамилия администратора | Не менее 2 символов |
| **Пароль** | Пароль учётной записи администратора | Не менее 8 символов |
| **Язык панели** | Язык интерфейса панели: узбекский / русский / английский | По умолчанию: узбекский |

**Шаг 2 — Язык и сеть**:

| Поле | Что делает | Требование |
|---|---|---|
| **Часовой пояс** | Asia/Tashkent или Asia/Samarkand (оба UTC+5) | Обязательно |
| **Внешний IP-адрес** | Внешний (видимый из интернета) IP сервера — может потребоваться для SIP-транков | Необязательно, в формате IPv4 |
| **Локальные сети (CIDR)** | Какие сети считаются «внутренними» (для NAT) — по одному CIDR в строке | Обязательно, хотя бы одна корректная строка; по умолчанию: `10.0.0.0/8` |

## Как это делается

### Создание учётной записи администратора
1. На первой открывшейся странице скопируйте **Код установки** из консоли/терминала и введите его.
2. Введите **Логин**, **Полное имя** и **Пароль**.
3. При необходимости выберите **Язык панели** (узбекский/русский/английский).
4. Нажмите **Продолжить** — если код или поля неверны, будет показана ошибка.

### Настройка языка и сети
1. Выберите **Часовой пояс** (Asia/Tashkent или Asia/Samarkand).
2. Если известен внешний IP-адрес сервера, введите его в поле **Внешний IP-адрес** — можно оставить
   пустым и позже ввести на странице [Настройки → SIP](/docs/trunks).
3. В поле **Локальные сети (CIDR)** введите внутреннюю сеть(и), по одному CIDR в строке (например
   `10.0.0.0/8`) — значение по умолчанию уже заполнено, при необходимости измените его.
4. Нажмите **Завершить** — автоматически выполняется вход с учётной записью администратора и переход в
   [Панель управления](/docs/dashboard).

## Советы и ограничения

> [!WARNING]
> **Код установки** используется только один раз — после создания администратора эта страница закрывается
> полностью, повторно использовать код нельзя, и новый код не выдаётся.

> [!TIP]
> Важно правильно указать **Локальные сети (CIDR)** — этот список используется для корректной работы
> внутренних номеров за NAT (например, в локальной сети офиса). Если есть сомнения, оставьте значение по
> умолчанию `10.0.0.0/8`, а позже уточните при необходимости.

> [!TIP]
> **Внешний IP-адрес** можно оставить пустым — позже его можно ввести в любое время в разделе Настройки.

> [!NOTE]
> После второго шага отдельного этапа подтверждения (Apply Config) нет — введённые сетевые настройки
> начинают действовать немедленно.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| «Код установки неверен» | Код введён с ошибкой или взят с консоли другого сервера | Скопируйте и введите код заново именно с консоли/терминала этого сервера |
| Блокировка после многократного ввода неверного кода | Число попыток ограничено в целях безопасности | Подождите немного и попробуйте снова |
| «Пароль должен быть не менее 8 символов» / «Логин должен быть не менее 3 символов» и т.п. | Поле не соответствует требованию | Введите значение, соответствующее указанному требованию |
| Ошибка в поле CIDR | Строка введена в неверном формате (не вида `10.0.0.0/8`) | Запишите каждую строку в правильном формате CIDR |
| Страница повторно не открывается | Администратор уже создан — настройка одноразовая | Войдите обычным способом через страницу [Вход](/docs/kirish) |
