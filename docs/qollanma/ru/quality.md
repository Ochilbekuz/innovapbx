# Оценка качества

Для контроля того, как операторы общаются с клиентами — каждый звонок можно оценить по готовому **листу
оценки** (чек-листу), а затем посмотреть средний балл в разрезе внутренних номеров. Например, отвечая на
вопросы вроде «Соблюдён ли стандарт приветствия?» и «Решена ли проблема клиента?», звонку выставляется
процентная оценка.

## Где находится
Меню: **Отчёты → Оценка качества**. Кто видит: просматривать может любой, но только пользователь с
правом `reports:edit` может создавать/редактировать листы оценки и ставить/редактировать/удалять оценки
— пользователю без этого права показывается предупреждение «У вас нет прав на управление контролем
качества — доступен только просмотр».

## Основные понятия

- **Лист (чек-лист)** — шаблон оценки, состоящий из одного или нескольких критериев. Каждый критерий
  имеет тип **Да/Нет** или **Оценка 1–5**, свой **вес** и может быть отмечен как **Обязательный** — если
  такой критерий не выполнен, общий балл становится **0%**.
- **Оценка (evaluation)** — заполненные ответы по одному листу для одного звонка + процент балла (0–100%)
  + необязательный комментарий.
- Цвет балла: **≥80%** — зелёный, **50–79%** — жёлтый, **<50%** — красный.
- Один звонок можно оценить несколько раз (даже по разным листам).

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| **Лист** → Название | Название листа | — |
| Активен | Отображается при новой оценке | По умолчанию: активен |
| Текст критерия | Вопрос оценки | «Соблюдён стандарт приветствия» |
| Тип | Да/Нет или Оценка 1–5 | — |
| Вес | Доля критерия в общем балле | — |
| Обязательный | Если отмечен — при невыполнении весь балл 0% | По умолчанию: отключено |
| **Оценка** → Лист | По какому листу оценивается | — |
| Комментарий | Необязательный текстовый комментарий | — |

## Как это делается

### Создание нового листа оценки
1. На вкладке **Листы** нажмите кнопку **Новый лист**.
2. Введите название, отметьте статус **Активен**.
3. Кнопкой **Добавить критерий** добавьте каждый вопрос: текст, тип (Да/Нет или Оценка 1–5), вес, при
   необходимости отметьте **Обязательный**.
4. Нажмите **Добавить**.

### Оценка звонка
1. На странице [Истории звонков](/docs/cdr) в нужной строке нажмите кнопку **Оценить** (или откройте
   существующую оценку кнопкой **Редактировать** на вкладке **Оценки** этой же страницы).
2. В открывшейся панели выберите **Лист**.
3. Ответьте на каждый критерий (Да/Нет или оценка 1–5) — кнопка сохранения становится активной только
   после ответа на все критерии.
4. При необходимости напишите **Комментарий**.
5. Нажмите **Сохранить оценку** — процент балла рассчитывается автоматически.

### Редактирование или удаление листа/оценки
1. В нужной строке нажмите значок карандаша (редактирование) или корзины (удаление).
2. При удалении подтвердите ещё раз в диалоговом окне — действие необратимо.

### Просмотр сводки
1. Откройте вкладку **Сводка**.
2. Посмотрите общее количество оценок и средний балл, ниже — распределение **по внутренним номерам**.

## Советы и ограничения

> [!TIP]
> Используйте обязательный критерий только для случаев, когда нарушение правила действительно должно
> обнулять весь балл (например, угрозы в адрес клиента) — иначе средние баллы искусственно снизятся.

> [!WARNING]
> Удаление оценки или листа необратимо.

- Даже если лист неактивен, ранее сделанные по нему оценки остаются в истории — просто он не выбирается
  для новых оценок.
- В листе должен быть хотя бы один критерий, и текст всех критериев должен быть заполнен — иначе лист не
  сохранится.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Нет кнопки «Создать лист» | Нет права `reports:edit` | Запросите право у администратора ([Пользователи и роли](/docs/rollar)) |
| Не удаётся сохранить оценку | Не на все критерии дан ответ | Выберите Да/Нет или оценку 1–5 для каждого критерия |
| «В этом листе нет критериев» | Лист создан пустым | Отредактируйте лист, добавьте хотя бы один критерий |
| Средний балл заметно ниже ожидаемого | Слишком много обязательных критериев | Оставьте отметку «Обязательный» только для действительно важных критериев |
