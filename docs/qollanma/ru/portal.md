# Личный кабинет

**Личный кабинет** — персональная страница каждого пользователя для работы со своим внутренним номером:
управление DND и переадресацией, вход/выход из очереди, просмотр статистики за сегодня, прослушивание
последних звонков и голосовых сообщений, защита учётной записи двухфакторной аутентификацией.

## Где находится

Меню: **Пользователи → Личный кабинет**. Кто видит: любой вошедший в систему пользователь, по своим
данным (`me:*`). Если к учётной записи не привязан внутренний номер, на странице показывается сообщение
**«Внутренний номер не привязан»**, и остальные разделы не отображаются — обратитесь к администратору.

## Основные понятия

- **DND (не беспокоить)** — при включении звонки до вас не доходят.
- **Переадресация звонков** — безусловная переадресация всех входящих звонков на другой внутренний или
  внешний номер.
- **Follow Me** — правила последовательного звонка на другие номера при занятости/отсутствии ответа
  (подробнее — [Внутренние номера](/docs/extensions)).
- **Подключение телефона (QR)** — настройка мобильного приложения Linphone через QR-код без пароля;
  ссылка одноразовая и становится недействительной через 60 секунд.
- **Браузерный телефон** — чип софтфона в верхней части (header) страницы: звонки и приём вызовов прямо
  из браузера через WebRTC. Виден только пользователям с внутренним номером, у которого включён WebRTC.
- **2FA (двухфакторная аутентификация)** — необязательная, требует при входе 6-значный код из приложения.

## Поля

| Раздел | Что показывает/делает |
|---|---|
| **DND (не беспокоить)** | Переключатель включения/отключения + поле **Переадресация звонков** (внутренний или внешний номер) |
| **Статистика за сегодня** | **Звонки**, **Пропущенные**, **Время разговора** |
| Follow Me | В сокращённом виде — список последовательных правил |
| **Подключение телефона** | Кнопка открытия окна QR |
| **Мои очереди** | Каждая очередь: статус (**Вошёл**/**Вышел**/**На паузе**), кнопки **Войти**/**Выйти**/**Пауза**/**Продолжить** |
| **Последние звонки** | За последние 24 часа: время, направление, номер, отметка результата, длительность, запись звонка |
| **Мои оценки** | Оценённые варианты по контролю качества: дата, название чек-листа, процент баллов, комментарий |
| **Двухфакторная аутентификация (2FA)** | Включение/отключение, создание новых резервных кодов |
| **Голосовые сообщения** | От кого, дата, длительность, прослушать/удалить, отметка непрочитанного |

## Как это делается

### Включение DND и переадресации
1. На карточке **DND (не беспокоить)** включите переключатель (при необходимости).
2. В поле **Переадресация звонков** укажите внутренний или внешний номер (если оставить пустым,
   переадресация отключается).
3. Нажмите кнопку **Сохранить**.

### Подключение мобильного телефона через QR
1. Нажмите кнопку **Подключить телефон**.
2. Установите на мобильный телефон приложение Linphone, откройте **Настройки → Ассистент →
   «Сканировать QR»**.
3. Наведите камеру на QR-код — номер добавится автоматически. Если срок истёк, нажмите кнопку **Новый
   QR**.

### Вход, выход, пауза в очереди
1. На карточке **Мои очереди** найдите строку нужной очереди.
2. Для входа нажмите кнопку **Войти**; для выхода — **Выйти**.
3. Для временного перерыва нажмите **Пауза**, при желании укажите причину и подтвердите; при
   возвращении нажмите **Продолжить**.

### Звонок из браузера (браузерный телефон)
1. Нажмите на чип софтфона в верхней части страницы, чтобы открыть панель.
2. Наберите номер или введите с клавиатуры и нажмите кнопку **Позвонить**.
3. Во время разговора используйте кнопки отключения микрофона, удержания, перевода на другой номер или
   завершения вызова.

### Включение 2FA
1. На карточке **Двухфакторная аутентификация (2FA)** нажмите кнопку **Включить**.
2. Отсканируйте появившийся QR-код приложением-аутентификатором (например Google Authenticator) и
   подтвердите, введя код.
3. Сохраните показанные резервные коды в надёжном месте, нажмите **Готово**.

### Прослушивание или удаление голосового сообщения
1. В списке **Голосовые сообщения** найдите нужное сообщение.
2. Прослушайте через плеер; чтобы отметить как прочитанное, нажмите значок подтверждения.
3. Если не нужно, нажмите значок **Удалить**.

## Советы и ограничения

> [!WARNING]
> Ссылка QR **Подключения телефона** одноразовая — после того как телефон её получит, она становится
> недействительной через 60 секунд, пароль в самом QR не хранится.

> [!WARNING]
> Для доступа к микрофону браузерному телефону требуется **HTTPS** (или `localhost`) — на странице,
> открытой по обычному HTTP, микрофон не работает и показывается предупреждение.

> [!TIP]
> Если участие в очереди **статическое**, кнопки **Войти**/**Выйти** не отображаются — показывается
> запись «Статическое участие — для входа/выхода обратитесь к администратору».

> [!NOTE]
> Если к одному внутреннему номеру привязано несколько физических аппаратов, при прямых звонках звонят
> все одновременно; при звонке через участника очереди или по API звонит только одно устройство.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| «Внутренний номер не привязан» | К вашей учётной записи ещё не привязан внутренний номер | Обратитесь к администратору — привязка выполняется в разделе [Внутренние номера](/docs/extensions) |
| Предупреждение «Требуется HTTPS» | Панель открыта через HTTP | Откройте панель по адресу `https://` |
| «Нет доступа к микрофону» | Браузер не дал доступ к микрофону | Разрешите доступ к микрофону в настройках браузера, обновите страницу |
| «Данные устарели» (при сохранении DND) | Данные изменены из другого места | Нажмите показанную кнопку и сохраните заново |
| Срок действия QR-кода истёк | Прошло более 60 секунд | Нажмите кнопку **Новый QR** и отсканируйте снова |
