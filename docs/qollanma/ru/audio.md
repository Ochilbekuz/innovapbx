# Аудиотека

**Аудиотека** — центр всех звуковых сообщений, используемых в системе: приветствия IVR, тексты
объявлений, файлы музыки ожидания (MOH). Здесь можно загрузить файл, записать с микрофона или
автоматически создать аудио из текста (TTS) — затем эти файлы выбираются на других экранах (IVR,
Объявления, Очереди).

## Где находится

Меню: **Приложения → Аудиотека**. Кто видит: пользователи с правом `apps` редактируют, остальные только
просматривают.

## Основные понятия

- **Файл** — любой загруженный аудиофайл автоматически преобразуется в формат `WAV, 8 кГц, моно` (так
  требует Asterisk) — исходный формат может быть WAV/MP3/OGG/WEBM.
- **Класс музыки ожидания (MOH)** — набор, собранный из нескольких файлов, выбирается в [Очередях]
  (/docs/queues). Класс с именем `default` — основная музыка системы, его нельзя удалить.
- **Перемешивание** — при включении файлы класса воспроизводятся в случайном порядке, при отключении —
  по очереди в порядке списка.
- **Текст в аудио (TTS)** — при вводе текста система преобразует его в звук и сохраняет в библиотеке.
  Для работы на странице [Интеграции](/docs/integrations) должен быть настроен провайдер синтеза речи
  (Yandex).

## Поля

### Загрузка файла

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Файл | Загружаемое аудио | WAV, MP3 или OGG, до 20 МБ |

### Запись с микрофона

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Название записи | Имя сохраняемого файла | Необязательно, пусто — «Запись» |
| Длительность | Длительность записи | Не более 5 минут |

### Класс музыки ожидания

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Имя | Идентификатор класса | Только латинские буквы в нижнем регистре/цифры/`_`/`-`, 1–32 символа |
| Перемешивание файлов | Порядок случайный или по очереди | По умолчанию — отключено (по очереди) |
| Файлы | Аудио, включённые в класс | Выбираются из имеющихся файлов аудиотеки |

### Создание аудио из текста

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Название аудио | Имя сохраняемого файла | Пусто — берётся автоматически из текста |
| Текст | Текст, преобразуемый в звук | Не более 2000 символов |

## Как это делается

### Загрузка файла
1. На вкладке **Файлы** перетащите файл в указанную область или нажмите **Выбрать файл**.
2. Файл в формате WAV/MP3/OGG до 20 МБ загрузится автоматически и преобразуется в WAV 8 кГц моно.

### Запись с микрофона
1. В блоке **Или запишите с микрофона** нажмите **Начать запись** (браузер запросит доступ к
   микрофону).
2. Нажмите **Остановить**, введите название, **Сохранить**.

### Создание аудио из текста (TTS)
1. Сначала настройте провайдера синтеза речи на странице [Интеграции](/docs/integrations) (видно только
   администратору, если не настроено — карточка предупредит об этом).
2. На карточке **Создание аудио из текста** нажмите **Начать**, введите текст (не более 2000 символов).
3. Прослушайте результат кнопкой **Прослушать**, если всё подходит — введите название и **Сохранить**.

### Создание класса музыки ожидания
1. На вкладке **Музыка ожидания** нажмите **Новый класс**.
2. Укажите имя (только латинские буквы в нижнем регистре/цифры/`_`/`-`), прикрепите нужные файлы.
3. При необходимости включите **Перемешивание**, нажмите **Добавить**.
4. Выберите новый класс в поле «Музыка ожидания» в [Очередях](/docs/queues).

### Удаление файла
1. Нажмите значок корзины в конце строки.
2. Если файл используется в IVR/объявлении/классе MOH, удаление блокируется — сначала удалите эти
   связи.

> [!TIP]
> Для коротких и точных текстов приветствий TTS очень быстрый — без обращения в студию можно за
> несколько секунд подготовить сообщение вроде «Внимание, разговор записывается».

> [!WARNING]
> Класс музыки ожидания с именем `default` удалить нельзя — это стандартная музыка системы.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Файл не загружается | Формат не поддерживается или больше 20 МБ | Загрузите WAV/MP3/OGG/WEBM размером до 20 МБ |
| Кнопка TTS показывает «не настроено» | В [Интеграциях](/docs/integrations) не подключён синтез речи | Администратору нужно настроить интеграцию |
| Микрофон не работает | Браузер не дал разрешение или микрофон не найден | Разрешите доступ к микрофону в настройках браузера, повторите попытку |
| Не удаётся удалить файл | Используется в IVR/объявлении/классе MOH | Сначала удалите эти связи |
| Не удаётся удалить класс `default` | Это стандартный класс системы, удаление запрещено | Создайте другой класс и выберите его там, где нужно |
