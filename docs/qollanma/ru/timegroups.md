# Рабочее время

Когда офис не работает, звонки должны попадать в другое место (например на голосовую почту или ночному
дежурному). Раздел **Рабочее время** именно для этого: недельный график (когда «открыто»), список
праздников и «условие», разделяющее DID на два направления — всё собрано здесь.

## Где находится

Меню: **Маршрутизация → Рабочее время**. Кто видит: пользователи с правом `routing` редактируют,
остальные только просматривают.

## Основные понятия

- **Группа** — недельный график: несколько интервалов времени на каждый день (например «понедельник
  09:00–13:00, 14:00–18:00»). Задаётся щелчком или протягиванием по ячейкам.
- **Праздник** — особый день с датой (`ГГГГ-ММ-ДД`) и отметкой «повторяется ежегодно». Для условий с
  включённым `honor_holidays` праздничный день считается «закрытым» независимо от графика.
- **Условие** — привязывается к группе и задаёт два адреса: **когда открыто** и **когда закрыто**. Если
  выбрать это условие во **входящем маршруте**, звонок автоматически разделяется на два в зависимости от
  времени.
- **Режим (override)** — каждое условие можно также управлять вручную: `Автоматически` (по графику) или
  `Ночной режим` (принудительно закрыто). Кнопка луны/солнца на странице переключает именно это.
- **Код переключения** — необязательный код вида `*271`: позволяет переключать условие в ночной режим/
  автоматический с кнопок телефона (задаётся отдельно для каждого условия).

## Поля

### Группа

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Имя | Название группы | Не более 60 символов |
| График рабочего времени | Недельная сетка ячеек | По умолчанию — пусто (никогда не «открыто») |

### Праздник

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Имя | Название праздника | Не более 60 символов |
| Дата | В формате `ГГГГ-ММ-ДД` | — |
| Повторяется ежегодно | Если включено — считается в этот день/месяц каждый год | При добавлении включено по умолчанию |

### Условие

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Имя | Название условия | Не более 60 символов |
| Номер | Необязательно — для прямого набора | 2–10 символов `0-9*#` |
| Группа рабочего времени | По какому недельному графику считается | — |
| Учитывать праздники | Если включено — в праздничный день всегда «закрыто» | По умолчанию включено |
| Когда открыто | Адрес в состоянии «открыто» по графику | Внутренний номер, очередь, IVR, группа вызова, конференция, объявление, особый адрес, занято/завершение |
| Когда закрыто | Адрес в состоянии «закрыто» | Из того же списка |
| Код переключения | Необязательно, `*` + 2–4 цифры | Например `*271` |

## Как это делается

### Создание группы рабочего времени
1. На вкладке **Группы** нажмите **Добавить группу**.
2. Введите имя, отметьте рабочие часы на недельной сетке (щелчком или протягиванием).
3. Нажмите **Добавить**. Условия, привязанные к этой группе, сразу начнут работать по новому графику.

### Добавление праздников Узбекистана
1. На вкладке **Праздники** нажмите **Добавить праздники Узбекистана** — официальные праздники на
   текущий год добавятся автоматически.
2. Праздники, точная дата которых по году не определена (например религиозные праздники), будут
   пропущены — добавьте указанные в уведомлении дни вручную.

### Добавление праздника вручную
1. Нажмите **Новый праздник**, введите имя и дату.
2. Отключите «Повторяется ежегодно», если он не нужен (для разового дня).

### Создание условия рабочего времени и привязка к входящему маршруту
1. Сначала в **Группах** должна быть хотя бы одна группа.
2. На вкладке **Условия** нажмите **Добавить условие**, укажите имя, выберите группу рабочего времени.
3. Выберите адреса **Когда открыто** и **Когда закрыто** (например, открыто — очередь, закрыто —
   голосовая почта).
4. При необходимости настройте учёт праздников и код переключения, нажмите **Добавить**.
5. На экране [Входящие маршруты](/docs/inbound) направьте DID-номер на это условие — теперь звонок
   будет автоматически разделяться по времени.

### Ручное переключение условия в ночной режим
1. В таблице нажмите значок луны/солнца в строке условия — произойдёт переключение `Автоматически` ↔
   `Ночной режим`.
2. Это же действие можно выполнить с телефона, набрав **Код переключения**, заданный при редактировании
   условия.

### Удаление
1. Нажмите значок корзины в конце строки.
2. Если группа/условие используются где-то ещё (например во входящем маршруте), удаление блокируется и
   показывается, где именно используются — сначала удалите эти связи.

> [!TIP]
> Условие рабочего времени можно выбирать не только во **входящих маршрутах**, но и в полях «адрес»
> IVR/очереди/группы вызова — то есть разделение по «открыто/закрыто» можно применить в любой точке.

> [!WARNING]
> Условие, вручную переключённое в «Ночной режим», автоматически не вернётся обратно — даже если по
> графику «открыто», звонки будут попадать на адрес «закрыто», пока вы сами не переключите его обратно
> в «Автоматически».

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Условие всегда показывает «закрыто» | График группы пуст или не отмечен текущий день | Отредактируйте группу, отметьте нужные дни/часы |
| В праздничный день осталось «открыто» | В условии отключено «Учитывать праздники» | Включите в редактировании условия |
| Группу/условие не удаётся удалить | Используется где-то ещё (во входящем маршруте и т.д.) | Сначала удалите из указанного списка |
| Код переключения не работает | Код не соответствует формату или пуст | Введите в формате `*` + 2–4 цифры |
