# Группы вызова

**Группа вызова** направляет один звонок на несколько номеров: например, при звонке на группу
«Бухгалтерия» одновременно звонят телефоны всех сотрудников отдела. Отличие от очереди — здесь нет
логики ожидания/очереди, работает только принцип «кто первый ответит».

## Где находится

Меню: **Маршрутизация → Группы вызова**. Кто видит: пользователи с правом `routing` редактируют,
остальные только просматривают.

## Основные понятия

- **Стратегия** — каким образом звонок доходит до участников (см. таблицу).
- **Участник** — может быть внутренним номером **или** внешним номером (например мобильным), указать оба
  в одном участнике нельзя.
- **Префикс отображаемого номера** — текст, добавляемый перед входящим номером на телефоне оператора
  (например «ПРОДАЖИ: »), благодаря чему оператор видит, из какой группы звонок.
- Адрес **«Если никто не ответил»** — куда направляется звонок, если никто не поднял трубку (или
  истекла заданная продолжительность).

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Имя | Название группы | — |
| Номер | Необязательно — для прямого набора | 2–10 символов `0-9*#` |
| Стратегия | Порядок вызова участников | По умолчанию — **Все одновременно** |
| Длительность звонка (секунды) | Время ожидания ответа | 5–300, по умолчанию 20 |
| Участники | Список внутренних и/или внешних номеров, по порядку | — |
| Префикс отображаемого номера | Добавляется перед входящим номером на экране оператора | Необязательно, например `ПРОДАЖИ: ` |
| Если никто не ответил | Адрес, куда переходит звонок по истечении времени | Обязательно |

### Стратегии

| Стратегия | Как работает |
|---|---|
| Все одновременно (`ringall`) | Звонит сразу всем участникам (по умолчанию) |
| По очереди (`hunt`) | По порядку списка, один за другим, каждому в течение заданной продолжительности звонка |
| Нарастающий (`memoryhunt`) | Звонит первому участнику, затем 1+2, затем 1+2+3… — предыдущие продолжают звонить |

## Как это делается

### Создание новой группы
1. Нажмите **Добавить группу**, выберите имя и стратегию.
2. Добавьте участников через **+ Добавить внутренний номер**; для внешнего номера введите номер в
   отдельное поле и добавьте (в формате `+998901234567`, 3–15 символов).
3. Выберите адрес **Если никто не ответил** (например голосовую почту).
4. Нажмите **Добавить**.

### Добавление внешнего номера
1. В поле «внешний» под списком участников введите номер и добавьте.
2. Номер в неверном формате или уже добавленный покажет ошибку.

### Изменение порядка участников
1. В стратегиях **По очереди** или **Нарастающий** порядок важен — перетащите строку в нужное место.

### Привязка группы вызова к входящему маршруту
1. На экране [Входящие маршруты](/docs/inbound) направьте DID-номер на эту группу.
2. Либо выберите её как адрес на клавише IVR/в условии рабочего времени.

### Удаление
1. Нажмите значок корзины в конце строки.
2. Если группа используется где-то ещё, удаление блокируется — сначала удалите эти связи.

> [!TIP]
> Задавайте **префикс отображаемого номера** отдельно для каждой группы — оператор, принадлежащий к
> нескольким группам, сможет по экрану видеть, из какого направления звонок.

> [!WARNING]
> Длительность звонка на внешний номер может приводить к дополнительным расходам по общему тарифу
> оператора — не задавайте «Длительность звонка» слишком большой.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Внешний номер не добавляется | Неверный формат или уже добавлен | Введите только цифры, 3–15 символов, `+` необязателен |
| В стратегии «Нарастающий» звонят все сразу | Длительность звонка слишком короткая, следующий участник быстро подключается | Увеличьте продолжительность |
| Не удаётся удалить группу | Используется во входящем маршруте или другом адресе | Сначала удалите эти связи |
