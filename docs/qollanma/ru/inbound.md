# Входящие маршруты

Входящие маршруты определяют, куда (внутренний номер, группа вызова, очередь, IVR, расписание рабочего
времени и т.д.) направляется звонок, пришедший извне (через транк оператора), в зависимости от того, на
какой DID-номер он поступил и с какого номера звонят.

## Где находится

Меню: **Подключение → Входящие маршруты**. Кто видит: право `connect:view`.
Добавление/редактирование/удаление — право `connect:edit`; при его отсутствии показывается подсказка
**«У вас нет прав на управление маршрутами — доступен только просмотр»**.

## Основные понятия

- **DID** — внешний телефонный номер, выделенный вам оператором; при включении **Любой DID** маршрут
  срабатывает независимо от того, на какой номер пришёл звонок.
- **CallerID (CID)** — фильтр по номеру звонящего; при включении **Любой номер звонящего** срабатывает
  независимо от того, кто звонит.
- **Источник поиска CID** — поиск имени звонящего номера во внешнем источнике (телефонная книга/CRM/HTTP)
  для отображения; дополнительный **префикс имени CID** добавляется перед именем звонящего.
- **Alert-Info** — необязательный SIP-заголовок для особого сигнала звонка или индикатора на аппарате.
- **Просмотр пути звонка** — показывает, куда в итоге попадает маршрут (цепочку очередь → IVR →
  внутренний номер и т.д.) в виде фактического дерева, рассчитанного сервером; по узлу можно нажать и
  перейти на соответствующую страницу.
- Отметка **«Удалён (#id)»** означает, что адрес маршрута (например удалённое IVR) больше не существует.

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| **Имя** | Название для распознавания маршрута | — (обязательно) |
| **Любой DID** / **DID** | На какой внешний номер маршрут срабатывает | DID: 3–15 цифр, например `712000001` |
| **Любой номер звонящего** / **CallerID (CID)** | На какой номер звонящего маршрут срабатывает | например `+998901234567` |
| **Назначение** | Куда направляется звонок | Внутренний номер, группа вызова, очередь, IVR или расписание рабочего времени |
| **Включён** | Временное отключение маршрута | по умолчанию включён |
| **Источник поиска CID** | Источник для поиска имени звонящего | по умолчанию: не выбрано |
| **Префикс имени CID** | Текст, добавляемый перед найденным именем | например `Приём: ` |
| **Alert-Info** | SIP-заголовок для особого сигнала/индикатора | например `Bellcore-dr2` |

## Как это делается

### Добавление нового входящего маршрута
1. Нажмите кнопку **Новый маршрут**.
2. Введите **Имя**; отключите **Любой DID** и введите конкретный номер DID (либо оставьте включённым).
3. При необходимости отключите **Любой номер звонящего** и введите конкретный CID.
4. В поле **Назначение** выберите, куда направить звонок.
5. Нажмите кнопку **Добавить**.

### Добавление источника поиска CID и Alert-Info
1. Откройте маршрут на редактирование.
2. Выберите **Источник поиска CID**, при необходимости введите **префикс имени CID**.
3. Если нужен особый сигнал, введите значение в поле **Alert-Info**, нажмите **Сохранить**.

### Просмотр пути звонка
1. В таблице в строке нужного маршрута нажмите значок пути (route).
2. В открывшейся панели посмотрите фактический путь звонка (например IVR → очередь → внутренний номер) в
   виде дерева.

## Советы и ограничения

> [!WARNING]
> Если адрес (IVR, очередь и т.д.) удалён, в таблице маршрутов появится отметка **«Удалён (#id)»** —
> звонки могут остаться без ответа, пока вы не настроите маршрут заново.

> [!TIP]
> Если на один DID нужно несколько маршрутов, используйте фильтр **CallerID (CID)**, чтобы направлять
> разных звонящих на разные адреса.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| «DID должен состоять из 3–15 цифр» | В поле DID введён неверный формат | Введите только цифры (без `+`) |
| «Неверный формат CallerID» | Поле CID не соответствует формату | Введите с `+` или напрямую цифрами (3–15 цифр) |
| «Неверный формат Alert-Info» | Введены недопустимые символы | Используйте только латинские буквы/цифры и символы `=<>:;/._@-` |
| «Удалён (#id)» | Адрес маршрута (IVR/очередь и т.д.) удалён | Отредактируйте маршрут и выберите новый адрес |
| Звонки не поступают | DID/CID не совпадают ни с одним маршрутом или маршрут отключён | Проверьте, что маршрут **включён**, и значения DID/CID, посмотрите «Путь звонка» |
