# Телефонная книга

**Телефонная книга** — список внешних контактов (клиенты, партнёры). Если звонит один из сохранённых
здесь номеров, в панели и на поддерживающих SIP-телефонах вместо номера отображается имя контакта.

## Где находится

Меню: **Приложения → Телефонная книга**. Кто видит: пользователи с правом `routing` редактируют,
остальные только просматривают.

## Основные понятия

- **Контакт** — состоит из имени (обязательно), организации и комментария (необязательно), а также
  одного или нескольких номеров.
- **Номера** — у каждого контакта может быть несколько номеров, для каждого можно указать необязательную
  метку (например «Мобильный», «Рабочий»).
- **Импорт/экспорт CSV** — можно выгрузить всю телефонную книгу в файл или сразу добавить/обновить много
  контактов из файла.

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Имя | Имя контакта | Обязательно, не более 128 символов |
| Организация | К какой организации относится | Необязательно, не более 128 символов |
| Комментарий | Дополнительная заметка | Необязательно, не более 512 символов |
| Номера | Один или несколько номеров контакта | Для каждого можно указать метку (например «Мобильный») |

## Как это делается

### Добавление нового контакта
1. Нажмите **Новый контакт**.
2. Введите имя, при необходимости организацию и комментарий.
3. Нажмите **Добавить номер** и введите нужные номера и необязательную метку.
4. Нажмите **Добавить**.

### Редактирование контакта
1. Нажмите кнопку редактирования в строке, измените поля, **Сохранить**.

### Поиск
1. Введите в поле поиска часть имени, организации или номера.

### Экспорт через CSV
1. Нажмите **Экспорт CSV** — вся телефонная книга загрузится в виде файла.

### Импорт через CSV
1. Нажмите **Импорт CSV**, выберите файл.
2. Система сначала показывает **предварительный просмотр** изменений (ничего не сохраняется) — сколько
   строк новых, сколько будет обновлено, сколько пропущено и число ошибок.
3. Если результат корректен, нажмите **Применить** — изменения сохраняются.
4. В файле должны быть столбцы `name`, `company`, `note`, `numbers`; в столбце `numbers` несколько
   номеров разделяются `;`, номер и метка — `:` (например `998901112233:Мобильный;998712223344:Рабочий`).

> [!TIP]
> Во время импорта строка, соответствующая существующему номеру, **обновляет существующий контакт**
> вместо создания нового (сопоставление происходит по номеру).

> [!WARNING]
> Импорт — единая цельная операция: если в файле найдена серьёзная ошибка, **ни одна строка не
> сохраняется** — сначала проверьте и исправьте список ошибок из результата предварительного просмотра.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Имя не отображается при звонке | Номера звонящего нет в телефонной книге или формат не совпадает | Добавьте номер в контакт в правильном формате |
| Строка импорта показана как «ошибка» | Пустой столбец `name` | Заполните поле имени в каждой строке |
| Импорт не обновил нужный контакт, а создал новый | Номер отличается по формату от прежнего (не проходит нормализацию) | Введите номер в правильном международном формате |
| Не удаётся удалить контакт | — (телефонная книга не используется в других местах, удаляется без ограничений) | — |
