# Обновление

Когда выходит новая версия Innova PBX, её можно установить прямо из панели, не заходя в терминал. Перед
обновлением делается **автоматическая резервная копия**, процесс отображается по этапам (резервная копия
→ код → установка → перезапуск), при ошибке сообщается причина вместе с журналом.

## Где находится
Меню: **Система → Обновление**. Кто видит: только пользователь с правами `*` (полный администратор).

## Основные понятия

- **Агент обновления** — работающая на сервере служба, которая выполняет само обновление. Если агент не
  найден (чаще всего в среде разработки), панель об этом сообщает и предлагает выполнить в терминале
  команду `sudo innova-update`.
- **Текущая версия** — номер версии, установленной на сервере сейчас, и время последней проверки.
- **Новая версия и список изменений (changelog)** — если при проверке найдена новая версия, показывается
  её номер и текст изменений (поддерживаются заголовки, списки, выделение жирным/кодом).
- **Окно подтверждения** — перед началом обновления нужно **вручную ввести** номер версии для
  подтверждения — это защита от случайного нажатия кнопки.
- **Этапы** — Резервное копирование → Загрузка кода → Установка → Перезапуск; каждый этап отмечается на
  индикаторе процесса (stepper).
- **Прерывание связи во время перезапуска** — на этом этапе панель какое-то время не отвечает от
  сервера; это отдельно отмечается как **нормальное состояние**, а не ошибка.
- **Журнал** — технические сообщения, выводимые в ходе обновления, обновляются в реальном времени
  (каждые 2 секунды); при прокрутке вверх вручную автопрокрутка останавливается, вернуть её можно кнопкой
  **К концу**.
- **Итог** — при успешном завершении показывается «Обновлено» и кнопка обновления страницы; при неудаче
  — причина ошибки, имя файла резервной копии (если есть) и кнопка просмотра журнала.

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Текущая версия | Версия, установленная сейчас | — |
| Последняя проверка | Когда проверялось в последний раз | Ещё не проверялось |
| Новая версия | Номер найденной новой версии | — |
| Введите номер версии (подтверждение) | Должен точно совпадать для начала обновления | — |

## Как это делается

### Проверка обновлений
1. Нажмите кнопку **Проверить**.
2. Если найдена новая версия, показывается её номер и список изменений; если нет — выводится «У вас
   последняя версия».

### Начало обновления
1. Когда отображается новая версия, нажмите кнопку **Обновить**.
2. В открывшемся окне прочитайте предупреждения: будет сделана автоматическая резервная копия, процесс
   занимает 5–15 минут, звонки могут прерваться примерно на 1 минуту.
3. Введите показанный номер версии в поле **точно** как указано.
4. Нажмите **Начать** — процесс начинается сразу, этапы и журнал отображаются в реальном времени.

### Наблюдение за процессом
1. Сверху смотрите, на каком этапе находится процесс (Резервная копия/Код/Установка/Перезапуск).
2. Если на этапе перезапуска панель какое-то время не отвечает — подождите, это ожидаемое состояние.
3. При необходимости прокручивайте журнал вниз/вверх; чтобы вернуться к концу, нажмите **К концу**.

### Просмотр итога
1. При успешном завершении нажмите кнопку **Обновить страницу** — панель перезагрузится с новой версией.
2. При неудаче прочитайте причину ошибки, при необходимости нажмите **Показать журнал**, чтобы увидеть
   полный текст.

## Советы и ограничения

> [!WARNING]
> Во время обновления **не выключайте сервер вручную** и не перезагружайте его — это может прервать
> процесс и оставить систему в частично обновлённом состоянии (ошибка «Процесс был прерван»).

> [!TIP]
> Планируйте обновление на время, когда нет большой нагрузки — во время процесса звонки могут
> прерваться примерно на 1 минуту.

- На сервере без установленного агента обновления обновить через эту страницу нельзя — используется
  команда терминала `sudo innova-update`.
- Поле подтверждения версии должно совпадать точно — при другом вводе кнопка недоступна.
- Если резервное копирование не удалось, код ещё не изменён — система продолжает работать как прежде.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| «Обновление из панели не настроено» | На сервере нет агента обновления | Используйте команду терминала `sudo innova-update` |
| «Источник не настроен» | Не найден Git-репозиторий или upstream | Посмотрите причину в терминале командой `innova-update --check` |
| «Не удалось загрузить» (fetch_failed) | Ошибка сети или прав доступа | Проверьте интернет-подключение и повторите попытку |
| «Есть несохранённые изменения в коде» | На хосте внесены изменения вручную | Обратитесь к администратору |
| «Не удалось создать резервную копию» | Недостаточно места на диске или другая причина | Проверьте место на диске и повторите попытку — код ещё не изменён |
| «Ошибка установки» | Этап после резервного копирования завершился неудачно | Обратитесь к администратору — может понадобиться восстановление из копии |
| «Процесс был прерван» | Предыдущее обновление не завершилось из-за перезапуска сервера | Проверьте статус и повторите попытку |
| «Номер версии не совпадает» | В поле подтверждения введён неверный номер | Введите показанный номер версии точно |
| «Страница была устаревшей» | Статус изменился в другом месте (409) | Статус обновился автоматически — проверьте ещё раз |
