# Источники поиска CID

Источник поиска CID — настройка, привязываемая к [входящему маршруту](/docs/inbound), которая при
поступлении звонка находит имя звонящего (например, в телефонной книге, CRM или внешней HTTP-службе) и
показывает его на экране/аппарате.

## Где находится

Меню: **Подключение → Источники поиска CID**. Кто видит: право `connect:view`.
Добавление/редактирование/удаление — право `connect:edit`; при его отсутствии показывается подсказка
**«У вас нет прав на управление этими источниками — доступен только просмотр»**. Кнопка проверки работает
и с правом только на просмотр.

## Основные понятия

- **Тип источника**:
  - **Телефонная книга** — поиск по записям внутренней телефонной книги системы.
  - **CRM** — поиск через подключённую интеграцию с CRM.
  - **HTTP (JSON)** — отправляет запрос на указанный HTTP-адрес и извлекает имя из ответа в формате JSON.
- Символ `{number}` в **HTTP-адресе** автоматически заменяется номером звонящего (например
  `https://crm.local/lookup?q={number}`).
- **Путь JSON** — какое поле из ответа HTTP взять как имя (например `data.name`).
- **Таймаут** и **Время кеша** — сколько ждать ответа на запрос и сколько времени хранить результат
  (чтобы не отправлять повторный запрос при следующих звонках с того же номера).
- **Проверка** — доступна в строке для любого источника; введя номер, можно сразу увидеть результат
  (найдено/не найдено/ошибка) и время ответа.

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| **Имя** | Название для распознавания источника | — (обязательно) |
| **Тип** | Телефонная книга / CRM / HTTP (JSON) | по умолчанию: Телефонная книга |
| **HTTP-адрес** | *(только для типа HTTP)* URL, вызываемый для поиска | `https://crm.local/lookup?q={number}` (обязательно для типа HTTP) |
| **Путь JSON** | *(только для типа HTTP)* Путь к полю с именем в ответе | `data.name` |
| **Таймаут (мс)** | Время ожидания ответа на запрос | по умолчанию: 1500 |
| **Время кеша (сек)** | Сколько времени хранится результат | по умолчанию: 3600 |
| **Включён** | Временное отключение источника | по умолчанию включён |

## Как это делается

### Добавление нового источника (телефонная книга или CRM)
1. Нажмите кнопку **Новый источник**.
2. Введите **Имя**, в поле **Тип** выберите **Телефонная книга** или **CRM**.
3. Нажмите кнопку **Добавить**.

### Добавление нового источника (HTTP)
1. Нажмите **Новый источник**, в поле **Тип** выберите **HTTP (JSON)**.
2. В поле **HTTP-адрес** укажите URL с placeholder `{number}` вместо номера.
3. При необходимости заполните **Путь JSON**, настройте **Таймаут** и **Время кеша**.
4. Нажмите кнопку **Добавить**.

### Проверка источника
1. В таблице в строке нужного источника нажмите значок проверки (колба).
2. Введите **Тестовый номер**, нажмите **Запустить**.
3. Результат: **«Найдено: <имя> (<мс> мс)»**, **«Не найдено (<мс> мс)»** или **«Ошибка: <сообщение>»**.

### Привязка источника к входящему маршруту
1. В разделе [Входящие маршруты](/docs/inbound) откройте нужный маршрут на редактирование.
2. В поле **Источник поиска CID** выберите созданный источник, при необходимости введите **префикс
   имени CID**, нажмите **Сохранить**.

### Удаление источника
1. В строке нажмите значок **Удалить**.
2. Если источник ещё используется в каком-либо входящем маршруте, система покажет, в каких именно
   маршрутах, и не разрешит удаление — сначала удалите его из маршрута.

## Советы и ограничения

> [!TIP]
> После добавления нового HTTP-источника сразу проверьте его на реальном номере кнопкой **Проверить** —
> ошибка в URL/пути JSON приведёт к тому, что входящие звонки будут отображаться без имени.

> [!TIP]
> Увеличение **времени кеша** снижает нагрузку на внешнюю службу, но изменения в CRM/телефонной книге
> могут не отражаться в течение этого времени.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| «Не найдено» (при проверке) | Номер отсутствует в источнике или неверный путь JSON | Проверьте путь JSON и данные в источнике |
| «Ошибка: ...» (при проверке) | Не удалось подключиться к HTTP-адресу или неверный формат ответа | Проверьте URL, сеть и формат JSON |
| Не удаётся удалить источник | Источник ещё используется в каком-либо входящем маршруте | Сначала удалите его из указанных маршрутов |
| Имя не отображается при звонке | Источник не привязан к входящему маршруту или не **включён** | В [Входящих маршрутах](/docs/inbound) привяжите источник к маршруту и проверьте, что он включён |
