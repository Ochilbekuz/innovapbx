# Парковка и перехват

**Парковка** позволяет временно поставить звонок на «место» и продолжить разговор из другой комнаты или с
другого телефона. Например: оператор парковкует звонок (переводом на `*70` или код парковки) и говорит
нужному сотруднику «подними место 701» — сотрудник набирает со своего телефона `701` и продолжает
разговор.

## Где находится

Меню: **Приложения → Парковка и перехват**. Кто видит: пользователи с правом `apps` редактируют, остальные
только просматривают. Настройка — **единая** для тенанта (создать новую «парковку» нельзя, можно только
редактировать существующие настройки).

## Основные понятия

- **Код парковки** — переводом (transfer) звонка на этот код можно его запарковать.
- **Начальный номер и количество мест** — диапазон номеров, по которым распределяются запаркованные
  звонки (например, начиная с 701, 20 мест — `701`–`720`).
- **По истечении времени** — если никто не поднял трубку, звонок **возвращается тому, кто парковал**,
  либо направляется **на другой адрес** (например, в очередь).
- **Музыка ожидания** — музыка, которую слышит звонящий, находясь в парковке.
- Кнопками телефона: подъём другого звонящего телефона в группе — `*8` (перехват по группе), подъём
  конкретного телефона — `**` (прямой перехват), парковка звонка — `*70` (стандартные [коды
  функций](/docs/featurecodes), можно изменить).

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Код парковки | Код, на который переводится звонок для парковки | По умолчанию `700`, 1–10 символов `0-9*#` |
| Начальный номер | Номер первого места парковки | По умолчанию `701` |
| Количество мест | Сколько будет мест парковки | 1–100, по умолчанию `20` |
| Время ожидания (секунды) | Сколько ждать, если никто не поднимает | 10–3600, по умолчанию `60` |
| По истечении времени | «Вернуть тому, кто парковал» или «Направить на другой адрес» | По умолчанию — возврат тому, кто парковал |
| Адрес по истечении времени | Если выбрано «На другой адрес» — куда | Необязательно |
| Класс музыки ожидания | Музыка, звучащая в парковке | Пусто — стандартная музыка |

## Как это делается

### Изменение настроек парковки
1. В блоке **Настройки** измените нужные поля (код, начальный номер, количество мест, время).
2. Если для **По истечении времени** выбрано «Направить на другой адрес» — укажите адрес.
3. Нажмите **Сохранить**.

### Парковка звонка (для пользователя)
1. Во время разговора переведите (transfer) звонок на код парковки (по умолчанию `700`).
2. Система назовёт свободный номер места (например `701`).
3. Сообщите этот номер другому сотруднику.

### Приём запаркованного звонка
1. С любого телефона наберите номер места парковки (например `701`) — разговор продолжится.

### Подъём звонящего телефона с другого места (перехват)
1. Для подъёма звонящего телефона в группе наберите код `*8` (перехват по группе).
2. Для подъёма конкретного телефона используйте код `**` (прямой перехват).

### Отслеживание запаркованных звонков в реальном времени
1. Таблица **Запаркованные звонки** обновляется автоматически каждые 5 секунд — отображается место,
   звонящий, кто запарковал, прошедшее время и время до истечения.

> [!TIP]
> Подбирайте **Количество мест** соразмерно величине команды — если много сотрудников парковкует
> одновременно, мест может не хватить.

> [!WARNING]
> Если для **По истечении времени** выбрано «Вернуть тому, кто парковал», отдельно проверьте, куда
> попадёт звонок, если паркующий уже положил трубку — иначе звонок может «зависнуть».

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Парковка не работает | Код парковки набран неверно или конфликтует с другим кодом | Проверьте точный код в настройках |
| Свободное место не найдено | Все места заняты | Увеличьте количество мест или обеспечьте более быстрый приём запаркованных звонков |
| По истечении времени звонок ушёл не туда | Адрес «По истечении времени» указан неверно | Проверьте и исправьте настройки |
