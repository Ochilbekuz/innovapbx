# Перенос

Чтобы не вводить вручную заново внутренние номера, транки, очереди, IVR, маршруты и похожие настройки,
работавшие на сервере FreePBX, используется мастер из 5 шагов: **Источник → Анализ → Проверка →
Применение → Результат**.

## Где находится
Меню: **Система → Перенос**. Кто видит: раздел виден всем, но начать и применить импорт может только
пользователь с правами `*` (полный администратор).

## Основные понятия

- **Скрипт экспорта** — скрипт (`innova-fpbx-export.sh`), запускаемый на сервере FreePBX от имени
  **root**, только читает данные (ничего не меняет); в результате создаётся архив
  `fpbx-export-*.tar.gz`.
- **Тип источника**: загрузка файла архива вручную или автоматическое получение по SSH — оба варианта
  ведут к одному и тому же анализу.
- **Анализ** — читает загруженный архив и строит **план** по объектам, подлежащим переносу (внутренний
  номер, транк, очередь, IVR, маршрут и т.д.); на этом этапе в Innova ничего не меняется.
- **Элемент плана и действие**: для каждого объекта указывается **Будет создано**, **Будет пропущено**,
  **Конфликт** (объект с таким именем/номером уже есть в Innova) или **Не поддерживается** (Innova не
  поддерживает такой объект).
- **Разрешение конфликта** — для конфликтующего элемента можно изменить действие на **Пропустить** или
  (если объект не создан вручную, «можно заменить») на **Заменить**.
- **Слабые пароли** — внутренние номера с SIP-паролем короче 12 символов; по умолчанию переносятся без
  изменений (чтобы не перенастраивать телефон), но при желании можно заменить на новый случайный пароль.
- **Применение** — фактическая запись плана в Innova; перед этим автоматически создаётся резервная копия
  текущего состояния.
- **Результат** — количество созданных/пропущенных/с предупреждением, CSV-отчёт, а если импорт не удался
  или нужно отменить — ссылка на восстановление резервной копии, сделанной перед импортом.

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Файл архива | В формате `fpbx-export-*.tar.gz`/`.tgz` | — |
| **SSH** → Хост/Порт/Пользователь | Подключение к исходному серверу | Порт по умолчанию: 22 |
| Пароль / Приватный ключ | Нужен хотя бы один из двух | — |
| Замена слабых паролей | Если включено — слабые SIP-пароли обновляются | По умолчанию: отключено |
| Слово подтверждения | Для запуска применения нужно ввести точно | `KOCHIRISH` |

## Как это делается

### Шаг 1 — Источник
1. На вкладке **Загрузка архива** сначала нажмите **Скачать скрипт**, затем запустите на сервере FreePBX
   от имени `root` команду `bash innova-fpbx-export.sh` — в результате будет создан файл архива.
2. Выберите полученный файл `.tar.gz`/`.tgz` и нажмите **Загрузить и перейти к анализу**.
3. Либо на вкладке **Через SSH** введите хост/порт/пользователя и пароль или приватный ключ, нажмите
   **Проверить соединение**, затем **Получить и перейти к анализу**. При первом подключении
   показывается отпечаток сервера — убедитесь, что он верный, и подтвердите.

### Шаг 2 — Анализ
1. Нажмите **Начать анализ** — отображается прогресс, в этот момент в Innova ничего не меняется,
   строится только план.

### Шаг 3 — Проверка
1. В карточках **По типам** посмотрите общее количество и число конфликтов для каждого типа объекта.
2. В таблице плана отфильтруйте по типу/действию, найдите нужные элементы и для конфликтующих строк
   измените действие на **Пропустить**/**Заменить**/**Создать** (объект, созданный вручную, заменить
   нельзя — только пропустить).
3. В разделе **Слабые пароли** при необходимости включите **Заменить слабые пароли на новые
   случайные**.
4. Нажмите **Перейти к применению**.

### Шаг 4 — Применение
1. Если пароль резервных копий не задан, страница предупредит об этом — сначала перейдите в настройки
   [Резервных копий](/docs/backup) и задайте пароль.
2. В поле подтверждения введите точно **«KOCHIRISH»**.
3. Нажмите **Применить** — процесс отображается с прогрессом.
4. Если план устарел (в Innova в это время произошло изменение), система предложит **Повторить анализ**
   — обновите план и подтвердите проверку заново.

### Шаг 5 — Результат
1. Посмотрите количество созданных/пропущенных/с предупреждением.
2. Кнопкой **Скачать отчёт (CSV)** сохраните полные подробности.
3. Если результат неудачный или импорт внёс непредусмотренные изменения — можно отменить его через
   ссылку **Отменить — восстановить резервную копию до импорта**.
4. Кнопкой **Начать новый импорт** запустите мастер заново.

### Просмотр/удаление истории прежних импортов
1. В таблице **История переносов** внизу страницы смотрите прежние импорты.
2. Ненужный файл архива удалите значком корзины — это удаляет с диска только **файл**, результат
   импорта (план, отчёт) сохраняется.

## Советы и ограничения

> [!WARNING]
> В архиве также есть **SIP-пароли** — после завершения импорта файл удаляется с сервера, но во время
> загрузки его нужно передавать по надёжному каналу.

> [!TIP]
> На этапах **Анализ** и **Проверка** в Innova ничего не меняется — можно спокойно изучить план, тщательно
> разрешить конфликты и только затем переходить к **Применению**.

- Одновременно может выполняться только одна задача резервного копирования/переноса — если идёт другая,
  **Применение** блокируется, нужно подождать её завершения.
- Пока не задан пароль резервных копий, перейти к этапу **Применение** нельзя (перед импортом нужна
  автоматическая резервная копия).
- Конфликт с объектом, созданным вручную (в самой Innova), можно только **пропустить**, **заменить**
  невозможно.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| «Выберите файл .tar.gz или .tgz» | Загружен файл другого формата | Выберите архив, созданный скриптом экспорта FreePBX |
| SSH «Не удалось подключиться» | Неверные хост/порт/пользователь/пароль | Проверьте данные и попробуйте снова |
| «Состояние Innova изменилось с момента анализа» | После анализа внесено другое изменение | Нажмите **Повторить анализ** |
| «Сейчас выполняется другая задача резервного копирования/переноса» | Выполняется параллельная задача | Подождите завершения предыдущей задачи и попробуйте снова |
| Действие не выполнено (в элементе плана) | Ошибка сервера или изменился статус объекта | Повторите анализ, чтобы обновить план |
| Результат «Неудачно» | В процессе импорта возникла ошибка | Прочитайте текст ошибки; верните состояние до импорта ссылкой **Отменить** |
