# Чёрный список

**Чёрный список** — список для автоматического отклонения входящего звонка по номеру звонящего.
Например: если внести в список постоянно беспокоящий рекламный номер, он больше не сможет дойти до
системы вообще.

## Где находится

Меню: **Приложения → Чёрный список**. Кто видит: пользователи с правом `apps` редактируют, остальные
только просматривают.

## Основные понятия

- **Номер** — блокируемый номер звонящего; перед сохранением система приводит его к каноническому виду
  (только `0-9`, 3–15 цифр).
- **Причина** — необязательный комментарий, почему номер заблокирован (например «спам»).
- **Блокировать скрытые/анонимные номера** — отдельный переключатель; если включён, отклоняются все
  звонки без показанного CallerID (скрытые, «anonymous», «restricted» и т.п.). Технически это тоже
  обычная запись списка — просто вместо номера сохраняется специальное значение `anonymous`, и в таблице
  она показывается отдельно.
- Блокировка работает **в реальном времени** — Asterisk проверяет список напрямую перед маршрутизацией
  входящего звонка, отдельная кнопка «применить» не нужна.

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Номер | Блокируемый номер звонящего | `+998901234567`; при сохранении нормализуется до 3–15 цифр |
| Причина | Комментарий о причине блокировки | Необязательно, например `спам` |
| Блокировать скрытые/анонимные номера | Отклонять звонки без показанного CallerID | По умолчанию — отключено |

## Как это делается

### Добавление номера в чёрный список
1. Нажмите **Добавить**.
2. В поле **Номер** введите номер звонящего (например `+998901234567`).
3. При необходимости укажите **Причину**.
4. Подтвердите **Добавить** — номер блокируется немедленно.

### Блокировка скрытых/анонимных номеров
1. Включите переключатель **Блокировать скрытые/анонимные номера** над таблицей.
2. Все звонки, не передающие CallerID (скрытые, анонимные), теперь автоматически отклоняются.
3. При отключении переключателя такие звонки снова проходят как обычно.

### Удаление номера из списка
1. Нажмите значок корзины в конце строки, подтвердите.
2. Номер немедленно разблокируется и снова может звонить.

> [!TIP]
> Через поле поиска можно быстро найти запись в списке по номеру или причине.

> [!WARNING]
> Если номер уже есть в списке, повторное добавление выдаст ошибку («Этот номер уже в чёрном списке») —
> сначала проверьте существующую запись.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Ошибка «Неверный номер — 3-15 цифр» | Введённое значение после нормализации не соответствует 3–15 цифрам | Введите номер в правильном формате, без букв/символов |
| «Этот номер уже в чёрном списке» | Номер уже был добавлен ранее | Если нужно отредактировать существующую запись, удалите её и добавьте заново |
| Нужный номер всё равно проходит | Номер приходит в другом формате (например с префиксом оператора) | При добавлении вводите номер полностью, в международном формате |
| Скрытые номера всё равно проходят | Переключатель отключён, либо оператор передаёт CallerID иначе | Проверьте, что переключатель включён; уточните у оператора передачу CallerID |
