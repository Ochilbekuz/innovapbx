# Очереди

**Очередь** — распределяет звонки между несколькими операторами (внутренними номерами). Например
«Очередь отдела продаж» — когда клиент звонит, звонит тому оператору, который свободен; если все заняты,
звонок ждёт в очереди и слышит музыку ожидания.

## Где находится

Меню: **Маршрутизация → Очереди**. Кто видит: пользователи с правом `routing` редактируют, остальные
только просматривают. Операторы управляют своим статусом в очереди (вход/выход/пауза) на странице
[Личный кабинет](/docs/portal).

## Основные понятия

- **Стратегия** — как звонок распределяется между операторами (см. таблицу).
- **Участник** — внутренний номер, привязанный к очереди, со **штрафным баллом** (penalty) — чем
  меньше балл, тем раньше звонит именно ему (используется для приоритета при равных стратегиях).
- **Динамический участник** — агент, который сам входит/выходит (обычно через [Личный
  кабинет](/docs/portal) добавляется/убирается из очереди); участники, добавленные админом через панель,
  считаются статическими.
- **Статус** — у каждого участника показывается отметка «Вошёл / На паузе / Вышел»; если указана причина
  паузы, она видна при наведении на отметку.
- **Музыка ожидания (MOH)** — музыка, проигрываемая звонящему до ответа оператора; если не выбрана,
  используется стандартная (основная) музыка.
- **Порог SLA** — за сколько секунд ответ на звонок считается «хорошим» (для отчётов, не продлевает
  ожидание).
- **Текущее состояние** — колонка «Текущее состояние» в таблице показывает число ожидающих в очереди и
  онлайн-участников прямо сейчас (обновляется в реальном времени).

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Имя | Название очереди | Не более 60 символов |
| Номер | Необязательно — для прямого набора | 2–10 символов `0-9*#` |
| Стратегия | Способ распределения | По умолчанию — **По кругу (с памятью)** |
| Участники | Список внутренних номеров, привязанных к очереди, каждый со штрафным баллом | Обязателен хотя бы 1 участник |
| По истечении времени ожидания | Адрес, на который звонок уходит, если никто не ответил | Обязательно |
| Музыка ожидания | Класс MOH | Пусто — стандартная (основная) |
| Звонок у агента (с) | Сколько звонит у каждого участника | 5–120, по умолчанию 15 |
| До следующей попытки (с) | Ожидание после отсутствия звонка | по умолчанию 5, минимум 1 |
| Пауза после звонка (с) | Время, в течение которого агент считается «занятым» после звонка | по умолчанию 0 |
| Максимальное ожидание (с) | Сколько максимум можно ждать в очереди, затем переход на адрес «По истечении времени ожидания» | по умолчанию 300 |
| Порог SLA (с) | Граница «хорошего ответа» для отчёта | по умолчанию 20 |
| Частота объявлений (с) | Как часто объявляется место в очереди | по умолчанию 60 (10–300) |
| Лимит мест в очереди | Сколько человек может одновременно ждать в очереди | Пусто — без ограничения |
| Объявлять позицию в очереди | Сообщение «Вы третий в очереди» | По умолчанию включено |
| Разрешить очередь без участников | Если отключено — звонок отклоняется при отсутствии участников | По умолчанию отключено |
| Записывать разговор | Запись разговоров, прошедших через очередь | По умолчанию включено |

### Стратегии

| Стратегия | Как работает |
|---|---|
| Все одновременно (`ringall`) | Звонит всем свободным участникам одновременно |
| Дольше всех отдыхал (`leastrecent`) | В первую очередь — участнику, который дольше всех не принимал звонки |
| Меньше всех принял (`fewestcalls`) | В первую очередь — участнику, принявшему меньше всего звонков |
| Случайно (`random`) | Звонит случайно выбранному участнику |
| По кругу (с памятью) (`rrmemory`) | По кругу, продолжая с того места, где остановилось в прошлый раз (по умолчанию) |
| По порядку (`linear`) | Всегда по порядку в списке, начиная с первого |
| Взвешенно-случайно (`wrandom`) | Случайный выбор с весом по штрафному баллу |

## Как это делается

### Создание новой очереди
1. Нажмите **Добавить очередь**, укажите имя и выберите стратегию.
2. Добавьте внутренние номера из списка **Участники** (хотя бы один обязателен), при необходимости
   измените штрафной балл.
3. Выберите адрес **По истечении времени ожидания** (обязательно) — например голосовую почту или
   ночного дежурного.
4. Нажмите **Добавить**.

### Изменение порядка участников
1. Откройте очередь для редактирования, в списке участников перетащите строку на новое место (порядок
   важен для стратегий `linear`/`rrmemory`).

### Удаление участника
1. Нажмите кнопку **Убрать** в строке участника, затем **Сохранить**.

### Открытие дополнительных настроек
1. Нажмите **Дополнительные настройки** внизу формы — там находятся время звонка у агента, интервал
   между попытками, SLA, частота объявлений и лимит очереди.

### Изменение музыки ожидания
1. В поле **Музыка ожидания** выберите готовый класс MOH (должен быть предварительно создан в [Аудиотеке]
   (/docs/audio)) или оставьте стандартную (основную).

### Привязка очереди к входящему маршруту
1. На экране [Входящие маршруты](/docs/inbound) направьте DID-номер на эту очередь.

### Удаление
1. Нажмите значок корзины в конце строки.
2. Если очередь используется где-то ещё (входящий маршрут, кнопка IVR и т.д.), удаление блокируется —
   сначала удалите эти связи.

> [!TIP]
> Колонка текущего состояния и надпись в заголовке формы «Сейчас: ожидает N, онлайн M» обновляются в
> реальном времени — по ним можно следить за нагрузкой на очередь.

> [!WARNING]
> Если «Разрешить очередь без участников» отключено и в очереди нет ни одного свободного/вошедшего
> участника — звонок отклоняется, даже на адрес «По истечении времени ожидания» он не попадёт.
> Убедитесь, что у вас всегда есть запасной адрес (например голосовая почта).

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Звонок не доходит до оператора | Агент не «вошёл» в очередь или на паузе | Оператору нужно войти через [Личный кабинет](/docs/portal) или снять паузу |
| Очередь всегда отклоняет как «занято» | Заполнен «Лимит мест в очереди» | Увеличьте лимит или оставьте поле пустым |
| Звонок сразу отклоняется | Нет участников, а «Разрешить очередь без участников» отключено | Добавьте участника или включите эту настройку |
| Очередь не удаляется | Используется во входящем маршруте или другом адресе | Сначала удалите эти связи |
