# Роли и права доступа

В Innova PBX каждому пользователю назначается **роль** — а роль определяет, какие разделы можно видеть и
изменять. Есть две готовые (системные) роли — **Admin** и **Operator** — а при желании можно создавать
собственные специальные роли.

## Основные понятия

- **Область** — разделы панели разбиты на шесть групп: **Мониторинг** (панель управления, мониторинг в
  реальном времени), **Внутренние номера** (внутренние номера, аппараты, голосовая почта), **Подключение**
  (транки, входящие/исходящие маршруты, наборы PIN-кодов, источники CID), **Маршрутизация** (рабочее время,
  IVR, очереди, группы вызова и т.д.), **Приложения** (аудио, конференции, парковка, чёрный список,
  кампании и т.д.), **Отчёты** (история звонков, отчёты, записи).
- **Уровень доступа** — отдельно для каждой области: **Нет** (не видно), **Просмотр** (только чтение),
  **Редактирование** (полное управление — Редактирование включает в себя Просмотр).
- Роль **Admin** — **полный** доступ ко всем областям, а также право входа в разделы, доступные только
  администратору — пользователи, роли, системные настройки, резервное копирование. Изменить или удалить
  её нельзя.
- Роль **Operator** — видит только **историю своих звонков** и работает в своём личном кабинете
  ([Личный кабинет](/docs/portal)); доступа ни к каким другим областям не имеет. Изменить или удалить её
  нельзя.
- **Специальная роль** — позволяет создать свой набор полномочий, выбрав отдельный уровень для каждой
  области (например, технический специалист, который может редактировать только «Подключение», а
  «Отчёты» видит только для просмотра).
- Пользователи, роли и другие разделы «Системы» (настройки, безопасность, резервное копирование, аудит и
  т.д.) — открыты **только для Admin**, специальной роли их выдать нельзя.
- Изменение роли вступает в силу **немедленно** — пользователю не нужно заново входить в систему.

## Как это делается

### Создание новой специальной роли
1. В разделе **Пользователи** откройте вкладку **Роли** (требуются права администратора).
2. Нажмите кнопку **Новая роль**, введите название роли.
3. В строке каждой области выберите нужный уровень (**Нет** / **Просмотр** / **Редактирование**).
4. Нажмите кнопку **Добавить**.

### Назначение роли пользователю
1. На вкладке **Пользователи** отредактируйте нужного пользователя (или создайте нового).
2. В поле **Роль** выберите нужную роль (системную или специальную), нажмите **Сохранить**.

### Изменение существующей специальной роли
1. На вкладке **Роли** отредактируйте строку нужной роли.
2. Измените уровни областей нужным образом, нажмите **Сохранить** — изменение сразу повлияет на всех
   пользователей с этой ролью.

## Советы и ограничения

> [!WARNING]
> Если для области дан только уровень **Просмотр**, пользователь не сможет ничего добавить/изменить/
> удалить в этом разделе — кнопки будут не видны или отключены.

> [!TIP]
> Системные роли (Admin, Operator) изменить нельзя — вместо этого создайте специальную роль со своим
> набором полномочий.

> [!WARNING]
> Роль, к которой привязаны пользователи, удалить нельзя — сначала переведите этих пользователей на
> другую роль.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Нужный раздел не отображается в меню | Роли пользователя не выдан уровень **Просмотр**/**Редактирование** для этой области | В разделе [Пользователи и роли](/docs/users) повысьте уровень области в роли |
| Кнопки (добавить/редактировать/удалить) не видны или не нажимаются | В роли для этой области есть только уровень **Просмотр** | При необходимости дайте роли уровень **Редактирование** |
| Не удаётся удалить роль | К роли ещё привязан(ы) пользователь(и) | Сначала переведите пользователей на другую роль |
| «Системную роль изменить нельзя» | Попытка редактировать роль Admin или Operator | Вместо этого создайте специальную роль |
