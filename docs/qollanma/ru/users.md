# Пользователи

Учётные записи, с которыми работают в панели управления (администратор, оператор и другие
пользовательские роли), и то, какие права просмотра или редактирования у них есть по каждой **области
(разделу)**, настраиваются здесь. Это не **внутренние номера** (телефон) — это **учётные записи доступа
к панели**.

## Где находится

Меню: **Система → Пользователи**, две вкладки: **Пользователи**, **Роли**. Кто видит: любой может
просматривать, но добавлять, редактировать и удалять может только пользователь с правами `*` (полный
администратор).

## Основные понятия

- **Пользователь** — логин, полное имя, email (необязательно), **роль**, необязательный привязанный
  **внутренний номер**, язык (uz/ru/en), статус активен/отключён, включена ли 2FA (двухфакторная
  аутентификация).
- **Системные роли** — **Admin** (полные права на все области) и **Operator** (видит только историю
  своих звонков); они **не изменяются и не удаляются**, открываются только для просмотра.
- **Пользовательская роль** — создаваемая помимо системных ролей роль; по каждой **области**
  (Мониторинг, Внутренние номера, Подключение, Маршрутизация, Приложения, Отчёты) отдельный уровень:
  **Нет / Просмотр / Редактирование**.
- **Область** — страниц из группы `system` (раздел Система) нет в этом списке — к ним может получить
  доступ только `*` (полный администратор), никакой другой ролью.
- **Привязка к внутреннему номеру** — один внутренний номер может быть привязан только к **одному**
  пользователю панели; уже привязанные номера не отображаются в списке выбора.
- **Сброс 2FA** — если пользователь потерял своё устройство, администратор может сбросить его 2FA **без
  запроса кода**, чтобы он мог подключить её снова при следующем входе.
- **Защита от самоограничения** — текущий пользователь не может удалить собственную учётную запись,
  изменить собственную роль и статус активности (чтобы случайно не потерять доступ к системе).

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Логин | Имя пользователя для входа | — |
| Полное имя | Отображаемое имя | — |
| Email | Необязательно | — |
| Роль | Admin / Operator / пользовательская роль | По умолчанию: Operator |
| Внутренний номер | Необязательная привязка | Не привязан |
| Язык | uz/ru/en | — |
| Пароль | Не менее 10 символов | — |
| Активен | При отключении — не может войти | — |
| **Роль** → Название | 1–40 символов | — |
| **Роль** → Уровень по области | Нет / Просмотр / Редактирование (для каждой области) | По умолчанию: Нет |

## Как это делается

### Добавление нового пользователя
1. На вкладке **Пользователи** нажмите **Новый пользователь**.
2. Введите логин, полное имя, email (необязательно), роль, необязательный внутренний номер, язык и
   пароль (не менее 10 символов).
3. Нажмите **Добавить**.

### Редактирование пользователя
1. В списке нажмите нужную строку или значок карандаша.
2. Измените имя, email, роль, внутренний номер, статус активности; если не хотите менять пароль,
   оставьте поле пустым.
3. Нажмите **Сохранить**.

### Сброс 2FA
1. В строке пользователя с включённой 2FA нажмите значок щита.
2. Подтвердите — пользователь теперь может войти без запроса кода и при следующем входе должен
   подключить 2FA заново.

### Удаление пользователя
1. Нажмите значок корзины, подтвердите в открывшемся окне — учётная запись **удаляется навсегда**.
2. Удалить собственную учётную запись нельзя — для себя эта кнопка отключена.

### Создание пользовательской роли
1. На вкладке **Роли** нажмите **Новая роль**.
2. Введите название роли (1–40 символов).
3. В строке каждой области укажите уровень **Нет / Просмотр / Редактирование**.
4. Нажмите **Добавить**.

### Редактирование/удаление роли
1. В строке пользовательской роли нажмите значок карандаша, измените название/права, нажмите
   **Сохранить**.
2. Для удаления нажмите значок корзины — если к роли привязаны пользователи, их сначала нужно перевести
   на другую роль.
3. Системные роли (**Admin**, **Operator**) не удаляются/не редактируются — при открытии показывается
   только описание.

## Советы и ограничения

> [!WARNING]
> Через пользовательскую роль нельзя дать права на страницы из группы `system` (раздел Система) — к ним
> может получить доступ только **Admin** (полный `*`).

> [!TIP]
> Операторам в большинстве случаев достаточно уровня **Просмотр** — давайте **Редактирование** только
> тем областям, где действительно нужны права на изменение.

- Один внутренний номер нельзя привязать к двум пользователям.
- Свою собственную роль и статус активности изменить нельзя.
- Пока к роли привязаны пользователи, она не удаляется.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| «К этой роли привязано N пользователей» | Перед удалением к роли ещё привязаны пользователи | Сначала переведите пользователей на другую роль |
| Новый пользователь не добавлен (ошибка логина) | Логин уже занят | Выберите другой логин |
| Внутренний номер отсутствует в списке выбора | Номер привязан к другому пользователю | Сначала снимите старую привязку |
| «Не удалось удалить» | Ошибка сервера или нет прав | Повторите попытку, проверьте права |
| Кнопки редактирования/удаления отключены | Нет прав полного администратора | Запросите у администратора права `*` |
