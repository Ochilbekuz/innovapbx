# Виджет обратного звонка

**Виджет** — небольшой скрипт, размещаемый на сайте, который показывает кнопку/форму, где клиент может
оставить номер телефона. После того как клиент оставит номер, система сначала звонит **оператору**
(внутреннему номеру/очереди/группе/IVR), затем клиенту и соединяет их. Например: кнопка «Перезвоните
нам» на сайте — клиент оставляет номер, система тут же звонит в отдел продаж, затем клиенту.

## Где находится

Меню: **Настройки → Интеграции → Виджет для сайта** (`/settings/integrations/widget`). Кто видит:
пользователи с правом `connect` редактируют, остальные только просматривают.

## Основные понятия

- **Публичный ключ (public_key)** — идентификатор, автоматически выдаваемый каждому виджету и
  размещаемый в коде на сайте; не требует JWT/логина, поэтому для защиты от использования на недоверенных
  сайтах важен список **Разрешённые сайты**.
- **Получатель (адресат)** — на какой внутренний номер/очередь/группу/IVR звонит система в первую
  очередь по заявке клиента.
- **Разрешённые сайты** — скрипт виджета работает только на доменах из этого списка (например
  `https://site.ru`); если список пуст, виджет вообще не работает.
- **Группа рабочего времени** — привязка к условию [Рабочего времени](/docs/timegroups); если не
  выбрана, виджет считается всегда открытым.
- **Вне рабочего времени** — «Не принимается» (заявка отклоняется) или «Ставится в очередь» (звонок
  совершается при начале рабочего времени).
- **Число попыток/Интервал повтора** — если оператор не отвечает, сколько раз и через какой интервал
  повторяется попытка.
- **Префикс CallerID** — знак, добавляемый перед именем, видимым на телефоне оператора (например
  «Сайт:»).
- **Внешний вид** — цвет кнопки, положение (слева/справа) и тексты заголовка/кнопки/сообщения об успехе
  для языков uz/ru/en.
- **Журнал заявок** — статус каждой поступившей заявки (в очереди, звонок, соединено, неуспешно,
  отклонено, отменено) и история попыток.

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Название | Название виджета (внутреннее, видно только в панели) | Не более 128 символов |
| Получатель (со стороны оператора) | На какой адрес звонок идёт первым | Внутренний номер, очередь, группа или IVR |
| Разрешённые сайты | Домены, на которых работает виджет | Например `https://site.ru`; пусто — не работает |
| Группа рабочего времени | По какому графику считается открыт/закрыт | Не выбрано — всегда открыт |
| Вне рабочего времени | Отклонение или постановка в очередь | По умолчанию — «Ставится в очередь» |
| Число попыток | Сколько раз звонить, если оператор не отвечает | 1–5, по умолчанию `2` |
| Интервал повтора (секунды) | Ожидание между попытками | 60–1800, по умолчанию `120` |
| Префикс CallerID | Дополнительный текст, видимый на экране оператора | Не более 16 символов, например `Сайт:` |
| Разрешить международные номера | Принимать ли номер, если клиент ввёл международный (+номер) | По умолчанию — отключено |
| Цвет (HEX) | Цвет кнопки | Например `#0f766e` |
| Положение | Кнопка в левом/правом углу экрана | По умолчанию — справа |
| Текст заголовка / кнопки / сообщения об успехе | Тексты для языков uz/ru/en | — |

## Как это делается

### Создание нового виджета
1. Нажмите **Новый виджет**, введите название.
2. Выберите **Получателя** (внутренний номер/очередь/группу/IVR).
3. Добавьте в список **Разрешённые сайты** хотя бы один домен (например `https://site.ru`).
4. При необходимости укажите группу рабочего времени, число попыток, префикс CallerID и настройки
   внешнего вида.
5. Нажмите **Создать**.

### Размещение виджета на сайте
1. В строке созданного виджета откройте блок **Код для вставки на сайт**.
2. Нажмите **Скопировать код** и разместите его на своём сайте перед тегом `</body>`.
3. Если адрес сервера (`public_base_url`) не настроен, система об этом предупредит — нужно обратиться
   к администратору.

### Редактирование виджета
1. Нажмите кнопку редактирования в строке, измените нужные поля, **Сохранить**.

### Обновление ключа (rotate)
1. Если считаете, что публичный ключ (public_key) скомпрометирован/используется не по назначению,
   нажмите кнопку **обновить ключ**.
2. **Примечание**: старый адрес перестанет работать — потребуется заменить ссылку на скрипт на сайте.

### Просмотр журнала заявок
1. Перейдите на вкладку **Журнал заявок** — показываются время, телефон/имя, статус, число попыток
   каждой заявки и (если неуспешно) текст ошибки.

### Удаление
1. Нажмите значок корзины в конце строки, подтвердите — виджет удаляется, скрипт на сайте перестаёт
   работать.

> [!WARNING]
> Не оставляйте список **Разрешённые сайты** пустым — иначе виджет вообще не будет работать. Добавляйте
> только домены, реально принадлежащие вам, иначе чужие сайты также смогут использовать скрипт.

> [!TIP]
> Указав **Префикс CallerID**, оператор сразу поймёт, что входящий звонок пришёл с сайта.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Виджет вообще не отображается на сайте | Домен сайта отсутствует в **Разрешённых сайтах** или список пуст | Добавьте правильный домен (с https) |
| Предупреждение «Адрес сервера не настроен» | `public_base_url` не настроен на уровне системы | Обратитесь к администратору для настройки общего адреса |
| Клиент оставил номер, но звонок не поступил | Условие рабочего времени в состоянии «Не принимается» или получатель занят | Проверьте настройку рабочего времени и получателя |
| Международный номер не принят | Отключено **Разрешить международные номера** | При необходимости включите эту опцию |
| Старый скрипт перестал работать | Ключ обновлён (rotate), но код на сайте не заменён | Скопируйте новый «Код для вставки на сайт» и разместите на сайте |
