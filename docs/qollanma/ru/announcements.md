# Объявления

**Объявление** — воспроизводит звонящему одно аудиосообщение, а затем переводит его на указанный
следующий адрес. Например: после сообщения «Внимание, разговор записывается для контроля качества»
звонок направляется в очередь.

## Где находится

Меню: **Маршрутизация → Объявления**. Кто видит: пользователи с правом `routing` редактируют, остальные
только просматривают.

## Основные понятия

- **Аудиофайл** — текст сообщения в виде звука должен быть предварительно загружен в [Аудиотеку]
  (/docs/audio).
- **Следующий адрес** — куда идёт звонок после окончания (или пропуска) сообщения.
- **Разрешить пропуск** — при включении звонящий может нажать `#`, чтобы пропустить сообщение не
  дослушав до конца.
- **Кнопка повтора** — при нажатии указанной кнопки сообщение воспроизводится заново с начала.
- **Начинать звонок с ответа** — при включении звонок считается «отвеченным» ещё до начала сообщения
  (важно для биллинга/CDR — иначе во время сообщения звонок всё ещё считается «без ответа»).

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Название | Название объявления | Не более 128 символов |
| Аудиофайл | Сообщение, воспроизводимое звонящему | Обязательно |
| Следующий адрес | Куда переходит звонок после сообщения | Обязательно — внутренний номер, очередь, IVR, группа вызова, условие рабочего времени, конференция, другое объявление и т.д. |
| Разрешить пропуск | Пропуск сообщения клавишей `#` | По умолчанию отключено |
| Кнопка повтора | При нажатии сообщение начинается заново | Один символ `0-9*#`, необязательно — если не выбрано, повтора нет |
| Начинать звонок с ответа | Отметка звонка как отвеченного до сообщения | По умолчанию включено |

## Как это делается

### Добавление нового объявления
1. Сначала загрузите аудио сообщения в [Аудиотеку](/docs/audio) (если не загружено, на странице появится
   напоминание).
2. Нажмите **Добавить объявление**, выберите название и аудиофайл.
3. Укажите **Следующий адрес** (обязательно).
4. При необходимости настройте пропуск, кнопку повтора и «начинать звонок с ответа».
5. Нажмите **Добавить**.

### Подключение объявления к входящему маршруту или IVR
1. На странице [Входящих маршрутов](/docs/inbound) направьте адрес DID на это объявление.
2. Либо выберите его как адрес в кнопке IVR/условии рабочего времени.

### Удаление
1. Нажмите значок корзины в конце строки.
2. Если объявление используется где-то ещё, удаление блокируется, и эти связи будут показаны — сначала
   удалите их.
3. Звонки, направленные на удалённое объявление, услышат сигнал занятости — очистите связи до удаления.

> [!TIP]
> Включайте «Начинать звонок с ответа» — иначе оператор сети может посчитать звонок «без ответа» во
> время сообщения (особенно важно для биллинга).

> [!WARNING]
> Не выбирайте тем же объявлением его собственный «Следующий адрес» — сообщение может повторяться
> бесконечно.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Добавление объявления заблокировано | Пока не загружено ни одного аудио | Загрузите файл в [Аудиотеку](/docs/audio) |
| При нажатии `#` сообщение не пропускается | Отключено «Разрешить пропуск» | Отредактируйте объявление и включите эту опцию |
| Не удаётся удалить объявление | Используется во входящем маршруте, IVR или другом адресе | Сначала удалите эти связи |
