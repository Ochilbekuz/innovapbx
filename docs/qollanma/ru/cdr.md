# История звонков

Полная история всех звонков через систему: кто кому звонил, когда, с каким результатом, и запись
разговора, если она велась.

## Где находится

Меню: **Отчёты → История звонков**.

## Основные понятия

- **Направление** — входящий, исходящий или внутренний звонок.
- **Результат (disposition)** — отвечен, не отвечен, занято или ошибка.
- **DID** — номер, на который поступил входящий звонок.
- **Счёт (accountcode)** — метка, по которой звонки группируются для учёта.
- **Качество (QA)** — оценка звонка по чек-листу качества.

## Поля

| Поле | Что показывает | Пример |
|---|---|---|
| Дата/время | Когда начался звонок | — |
| Источник | Номер/имя звонящего | — |
| Назначение | Куда шёл звонок | — |
| Направление | Входящий/исходящий/внутренний | — |
| Длительность | Длительность разговора | в секундах |
| Результат | Отвечен/не отвечен/занято/ошибка | — |
| DID | Номер, на который поступил звонок | — |
| Счёт | Метка учёта | — |
| Запись | Наличие аудиозаписи | — |
| Оценка качества | Балл по чек-листу, если оценивался | — |
| Транк | Через какой транк прошёл звонок | — |

## Как это делается

### Простой поиск
1. Введите номер, имя или период в строку поиска.
2. Нажмите **Искать** — список обновится по условиям.

### Расширенный поиск
1. Откройте **Расширенный поиск**, задайте направление, результат, транк и другие условия.
2. Нажмите **Применить** для фильтрации списка.

### Сохранение шаблона поиска
1. После настройки фильтров нажмите **Сохранить как шаблон**.
2. Укажите название — шаблон появится в списке для быстрого повторного использования.

### Прослушивание/скачивание/удаление записи
1. В строке звонка нажмите значок воспроизведения для прослушивания записи.
2. Кнопка **Скачать** сохраняет файл записи, кнопка **Удалить** — удаляет её безвозвратно.

### Оценка звонка
1. В строке звонка нажмите **Оценить**.
2. Выберите чек-лист и заполните оценку — см. [Оценка качества](/docs/quality).

### Добавление входящего номера в чёрный список
1. В строке звонка нажмите **В чёрный список** у номера источника.
2. Подтвердите — звонки с этого номера будут блокироваться.

### Экспорт в CSV
1. Настройте нужные фильтры.
2. Нажмите **Экспорт в CSV** для скачивания отфильтрованного списка.

## Советы и ограничения

> [!TIP]
> Сохранённые шаблоны поиска ускоряют повторяющиеся проверки — например, еженедельный отчёт по
> конкретному транку.

> [!WARNING]
> Удаление записи звонка необратимо — перед удалением убедитесь, что запись действительно не нужна.

- Расширенный поиск позволяет комбинировать несколько условий одновременно для точной фильтрации.
- Экспорт в CSV выгружает только те звонки, которые соответствуют текущим фильтрам.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Звонок не отображается в истории | Фильтры исключают его период/направление | Сбросьте фильтры или расширьте диапазон дат |
| Запись отсутствует | Политика записи отключена для номера | Проверьте настройки записи во внутреннем номере |
| Экспорт CSV не содержит нужных данных | Фильтры применены до экспорта | Проверьте и настройте фильтры перед экспортом |
| Оценка не сохраняется | Чек-лист не выбран или не заполнен полностью | Заполните все обязательные поля чек-листа |
