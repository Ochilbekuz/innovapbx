# Журнал аудита

Полный список того, кто что сделал в системе (кто создал, изменил, удалил, вошёл/не смог войти,
восстановил и т.д.). Например, если настройка транка неожиданно изменилась — здесь можно точно увидеть,
какой пользователь и когда её изменил, а также старое и новое значение.

## Где находится
Меню: **Система → Журнал аудита**. Кто видит: только пользователь с правами `*` (полный администратор).

## Основные понятия

- **Тип действия**: Создано, Изменено, Удалено, Вход, Ошибка входа, Восстановлено, Перезапущено,
  Временно изменено, Прослушивание/вход.
- **Объект** — над чем выполнено действие (например `trunk`, `extension`, `user`).
- Если для действия есть точные детали изменения, в строке появляется значок глаза — нажав на него,
  можно увидеть старые/новые значения. Пароли и другие секретные значения скрываются в журнале как
  `***`.
- В столбце «Кто» для действий, выполненных системой автоматически, показывается **система** (без
  пользователя).

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Начало / Конец | Диапазон дат | По умолчанию: последние 30 дней |
| Действие | Фильтр по типу действия | По умолчанию: Все |
| Тип объекта | Фильтр по тексту (необязательно) | `trunk`, `extension` |
| Поиск | Свободный поиск по логину или имени объекта (необязательно) | — |

## Как это делается

### Поиск изменений с помощью фильтров
1. Укажите дату **Начало**/**Конец**.
2. При необходимости выберите тип **Действие** (например только «Удалено»).
3. В поле **Тип объекта** введите текст, например `trunk`, `extension`, чтобы увидеть только записи
   этого типа.
4. В поле **Поиск** введите логин или имя объекта для быстрого нахождения.

### Просмотр деталей изменения
1. Нажмите значок глаза в конце строки (отображается только для записей с доступными деталями).
2. В открывшемся окне для каждого изменённого поля показывается **старое** (красное) и **новое**
   (зелёное) значение.

## Советы и ограничения

> [!TIP]
> При подозрительной ситуации (например неожиданное изменение конфигурации) — отфильтруйте по
> **Действие: Изменено** и нужному **Типу объекта**, чтобы быстро найти виновного пользователя и время.

- Журнал предназначен только для просмотра — удалить или отредактировать что-либо отсюда нельзя.
- Пароли и аналогичные секретные поля всегда отображаются как `***` — настоящее значение никогда не
  показывается.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| «По этому фильтру записей не найдено» | Диапазон дат или фильтр слишком узкий | Расширьте фильтры или проверьте заново |
| Значок глаза не отображается | Для этой записи детали изменения не сохранены (например действие входа) | Это нормальная ситуация — не для всех типов действий есть детали |
