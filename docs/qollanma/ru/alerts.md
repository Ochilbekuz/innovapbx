# Оповещения

При блокировке IP, блокировке по toll-fraud, достижении лимита одновременных вызовов или при
падении/восстановлении транка — система автоматически отправляет сообщение об этих событиях в выбранные
Telegram-чаты. Здесь настраивается, по каким событиям отправлять сообщение, в какие чаты и как часто.

## Где находится
Меню: **Система → Оповещения**. Кто видит: просматривать может любой, но изменять настройки и отправлять
тестовое сообщение может только пользователь с правом `*` (полный администратор).

## Основные понятия

- **Токен Telegram-бота** — должен быть предварительно настроен в разделе «Уведомления» на странице
  [SIP и сеть](/docs/sip); если токен не задан, в верхней части страницы появляется предупреждение со
  ссылкой на эту страницу.
- **ID чатов** — список Telegram-чатов, в которые отправляются сообщения (числовой ID, например
  `-1001234567890`); можно добавить сколько угодно чатов.
- **Типы событий** — каждый включается/отключается отдельно: IP заблокирован, блокировка по toll-fraud,
  лимит одновременных вызовов, транк недоступен, транк восстановлен.
- **Подавление повторов (dedup)** — одинаковое событие в течение заданного числа секунд повторно не
  отправляется (чтобы не было спама); `0` — отправляется каждый раз.
- **История** — статус каждого отправленного сообщения: ожидает, отправлено, ошибка, подавлено (из-за
  dedup), пропущено (тип события отключён, поэтому не отправлено).

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| ID чата | Telegram-чат для отправки (числовой) | `-1001234567890` |
| IP заблокирован (SIP-атака) | Отправка сообщения по этому событию | — |
| Блокировка по toll-fraud | Отправка сообщения по этому событию | — |
| Лимит одновременных вызовов | Отправка сообщения по этому событию | — |
| Транк недоступен | Отправка сообщения по этому событию | — |
| Транк восстановлен | Отправка сообщения по этому событию | — |
| Подавление повторов (секунды) | `0` — отправляется всегда | — |

## Как это делается

### Добавление/удаление ID чата
1. В блоке **ID чатов** введите ID Telegram-чата в поле (также работает клавиша `Enter`).
2. Нажмите **Добавить**.
3. Для удаления нажмите значок **×** на нужной метке чата.

### Выбор событий для отправки
1. В блоке **По каким событиям отправлять** включите/отключите нужные события.
2. В поле **Подавление повторов** укажите число секунд, ограничивающее, как часто повторяется одно и то
   же сообщение.
3. Нажмите **Сохранить**.

### Отправка тестового сообщения
1. В блоке **Тестовое сообщение** нажмите **Отправить тестовое сообщение**.
2. Система отправит реальное сообщение во все добавленные чаты с текущими настройками и покажет
   результат (в сколько чатов удалось доставить).
3. Отправленное сообщение также отображается в таблице **История**.

### Просмотр истории сообщений
1. В таблице **История отправленных оповещений** внизу страницы посмотрите время, текст сообщения и его
   статус.

## Советы и ограничения

> [!WARNING]
> Если токен Telegram-бота не настроен, ни одно сообщение не будет отправлено — сначала введите токен
> на странице [SIP и сеть](/docs/sip).

> [!TIP]
> После изменения настроек сразу нажмите **Отправить тестовое сообщение**, чтобы убедиться, что ID чата
> указан верно.

- Один и тот же ID чата не добавляется дважды.
- Повторное событие, пришедшее в окне dedup, фиксируется в истории как **подавлено**, сообщение не
  отправляется — это не ошибка.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Баннер «Токен Telegram-бота не настроен» | На странице SIP не введён токен | Настройте токен на странице [SIP и сеть](/docs/sip) |
| Тестовое сообщение «Не удалось отправить» | Неверный токен или чат заблокировал бота/бот не добавлен в чат | Проверьте токен и ID чата; добавьте бота в нужную группу/чат |
| Событие произошло, но сообщение не пришло | Этот тип события отключён или подавлен в окне dedup | Проверьте **По каким событиям отправлять**; посмотрите статус в **Истории** |
| «Настройки были изменены в другом месте» | Другой администратор сохранил их в то же время | Страница обновит значения — проверьте и сохраните заново |
