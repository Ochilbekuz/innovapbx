# Голосовая почта

**Голосовая почта** — ящик, в который звонящий может оставить сообщение, если на звонок не ответили.
Например: «Если офис закрыт, звонок должен попадать в голосовую почту» — достаточно выбрать этот ящик
как адрес «закрыто» в условии [Рабочее время](/docs/timegroups).

## Где находится

Меню: **Приложения → Голосовая почта**. Кто видит: пользователи с правом `extensions` редактируют,
остальные только просматривают. Владелец прослушивает свои сообщения на странице [Личный
кабинет](/docs/portal).

## Основные понятия

- **Владелец** — ящик может быть двух видов: привязан к конкретному **внутреннему номеру**, или
  **общий ящик** (не принадлежит ни одному внутреннему номеру, используется только как адрес в
  маршрутизации).
- **Номер ящика** — идентификатор голосовой почты (2–10 цифр); при привязке к внутреннему номеру
  становится таким же номером автоматически, в общем ящике указывается вручную.
- **PIN** — пароль, запрашиваемый при входе в ящик с телефона.
- **Уведомление (email/Telegram)** — отправляет оповещение при поступлении нового сообщения; можно
  также прикрепить аудиофайл.
- **Приветствие** — сообщение, которое слышит звонящий; если не выбрано, используется стандартное
  приветствие.
- Прослушивание своего ящика с телефона — `*97`; прослушивание ящика другого внутреннего номера — `*98`
  (стандартные коды функций, можно изменить на странице [Коды функций](/docs/featurecodes)).

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Владелец | Внутренний номер или общий ящик | — |
| Внутренний номер | Если владелец — «внутренний номер» — какой именно | Из списка номеров, у которых ещё нет ящика |
| Номер ящика | Если владелец — «общий» — идентификатор ящика | 2–10 цифр |
| PIN | Пароль для входа в ящик | При создании обязателен (4–8 цифр), при редактировании пустое значение не меняет пароль |
| Email | Адрес для уведомления | Необязательно |
| Уведомление по email | Отправка на email при новом сообщении | По умолчанию отключено |
| Уведомление в Telegram | Отправка в Telegram при новом сообщении | По умолчанию отключено |
| Telegram chat ID | В какой чат отправлять | Например `123456789` или `@имя_канала` |
| Прикреплять аудио | Звук сообщения добавляется к email/Telegram как файл | По умолчанию отключено |
| Приветствие | Сообщение, которое слышит звонящий | Пусто — стандартное приветствие |

## Как это делается

### Создание ящика для внутреннего номера
1. Нажмите **Создать ящик**, выберите **Владелец** — «Внутренний номер».
2. Выберите один из внутренних номеров, у которых ещё нет ящика.
3. Введите PIN (4–8 цифр), при необходимости включите email/Telegram-уведомления.
4. Нажмите **Создать**.

### Создание общего ящика
1. Выберите **Владелец** — «Общий ящик», вручную введите номер ящика (например `200`).
2. Введите PIN и настройки уведомлений, нажмите **Создать**.
3. Общий ящик можно выбрать как адрес в [условии рабочего времени](/docs/timegroups), [входящем
   маршруте](/docs/inbound), IVR и т.д.

### Включение email/Telegram-уведомлений
1. Откройте ящик для редактирования, введите email-адрес и включите **Уведомление по email** (либо
   укажите Telegram chat ID и включите **Уведомление в Telegram**).
2. При необходимости включите **Прикреплять аудио** — звук сообщения будет добавлен как файл.

### Настройка приветствия
1. Сначала загрузите сообщение в [Аудиотеку](/docs/audio).
2. При редактировании ящика выберите его в поле **Приветствие**.

### Прослушивание/удаление сообщений (через панель)
1. Откройте строку ящика, в разделе **Сообщения** посмотрите список.
2. Нажмите **Отметить прослушанным** или значок корзины для удаления.

### Удаление
1. В строке ящика нажмите значок корзины.
2. Если ящик используется где-то ещё (маршрут, IVR и т.д.), удаление блокируется — сначала удалите эти
   связи.

> [!TIP]
> Владелец внутреннего номера может прослушать свои сообщения с телефона (`*97`) или в браузере на
> странице [Личный кабинет](/docs/portal).

> [!WARNING]
> Если при редактировании оставить PIN пустым — старый PIN не меняется. Чтобы задать новый PIN, в поле
> нужно ввести полностью новое значение.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Номер отсутствует в списке внутренних номеров | У этого номера уже есть ящик | Удалите старый ящик или выберите другой номер |
| Email/Telegram-уведомление не приходит | Канал уведомления отключён или неверный адрес/chat ID | Проверьте настройки, убедитесь в [Интеграциях](/docs/integrations), что SMTP/Telegram подключены |
| `*97`/`*98` не работают | Код функции отключён или изменён | Проверьте текущий код в [Кодах функций](/docs/featurecodes) |
| Не удаётся удалить ящик | Используется в маршруте или IVR | Сначала удалите эти связи |
