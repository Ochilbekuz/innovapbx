# Доступ (SSH и веб-панель)

Здесь видно, как происходит подключение к серверу — порт **SSH** и порты HTTP/HTTPS **веб-панели** — и
можно безопасно их изменить. Смена порта, как и на странице **Firewall**, сначала применяется, затем
ожидает подтверждения: если не подтвердить, по истечении срока она **автоматически откатывается** к
прежнему порту — это защита от полной потери доступа к серверу.

## Где находится

Меню: **Система → Доступ**. Кто видит: только пользователь с правами `*` (полный администратор).

## Основные понятия

- **Статус SSH** — здесь видно, работает ли sshd, текущий порт, прослушиваемые порты и включён/выключен
  вход по паролю.
- **Инструкция входа** — команда `ssh -p <порт> innova@<host>` для текущего порта — копируется одной
  кнопкой **Копировать**.
- **Вход под root** — закрыт из соображений безопасности; после входа используется `sudo -i`.
- **Proxmox LXC / шаблон Debian** — пользователя `innova` нет, а root по умолчанию входит только по SSH-ключу,
  поэтому даже верный пароль даёт «Access denied». В консоли Proxmox (`pct enter <ID>`) выполните:
  `echo 'PermitRootLogin yes' > /etc/ssh/sshd_config.d/10-innova-root.conf && systemctl restart ssh` — затем входите как `root` с его паролем. Страница сама определяет этот случай и показывает команду.
- **Внешний firewall** — если сервер защищён внешним (хостинг/ufw) firewall, появляется напоминание
  открыть новый порт и там.
- **Поток Применение → Подтверждение** — как на странице **Firewall**: после **Применить** изменение
  сразу вступает в силу, но остаётся в состоянии **ожидания**, сверху виден обратный отсчёт.
- **При смене порта веб-панели** — после применения браузер автоматически переходит на публичную
  страницу подтверждения (`/access-confirm`) по новому адресу — там нужно нажать **Подтвердить**, чтобы
  перейти на новый адрес.

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Новый SSH-порт | Порт, который слушает служба SSH | 1–65535, например `2222` |
| HTTP-порт | Незашифрованный порт веб-панели | например `8080` |
| HTTPS-порт | Зашифрованный порт веб-панели | например `8443` |
| Время на подтверждение (секунды) | Срок подтверждения после применения | есть значение по умолчанию, можно изменить |

## Как это делается

### Смена SSH-порта
1. В разделе **SSH** введите нужный порт (1–65535) в поле **Новый SSH-порт**.
2. Нажмите **Применить** — изменение сразу вступает в силу и переходит в состояние **ожидания**.
3. Проверьте подключение по новому порту (командой `ssh -p <порт> ...`, показанной на странице).
4. Если всё работает — нажмите **Подтвердить**. Если не успеете в срок, порт **автоматически вернётся**
   к прежнему.

### Смена портов веб-панели
1. В разделе **Веб-панель** заполните **HTTP-порт** и/или **HTTPS-порт**.
2. Нажмите **Применить** — в появившемся диалоге с новым адресом нажмите **Применить** ещё раз.
3. Браузер автоматически перейдёт на страницу подтверждения по новому адресу — нажмите там
   **Подтвердить**, чтобы вернуться на страницу входа.
4. Если не успеете подтвердить в срок, порты **автоматически вернутся** к прежним.

## Советы и ограничения

> [!WARNING]
> Если из-за нового порта (особенно SSH) вы потеряете доступ — **не беспокойтесь**: если не подтвердить
> изменение, по истечении срока система **сама** вернёт прежний порт.

> [!TIP]
> Перед сменой порта веб-панели убедитесь, что окно/вкладка с новой ссылкой подтверждения не будет
> заблокирована блокировщиком всплывающих окон.

- Одновременно может быть только одно изменение в состоянии **ожидания** — пока оно не разрешено
  (подтверждено или автоматически откатано), новое применить нельзя.
- Если порт занят другой службой, при применении соответствующее поле выделяется красным.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| «Этот порт занят другой службой» | Введённый порт уже используется на сервере | Выберите другой свободный порт |
| Предупреждение о неработающем sshd | Служба SSH остановлена или не слушает заявленный порт | Проверьте состояние sshd на сервере |
| Изменение осталось в состоянии ожидания | Не подтверждено | Нажмите **Подтвердить** или дождитесь автоматического отката по истечении срока |
| Не удаётся подключиться к веб-панели по новому адресу | Новый порт не открыт во внешнем firewall | Откройте новый порт во внешнем (ufw/хостинг) firewall |
| Ссылка подтверждения не работает | Ссылка просрочена или неверна | Проверьте, что прежний адрес восстановился автоматически, попробуйте снова |
