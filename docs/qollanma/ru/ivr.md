# IVR

**IVR** (голосовое меню) — предлагает звонящему выбрать раздел с помощью аудио: «Для отдела продаж
нажмите 1, для бухгалтерии — 2». Каждая клавиша ведёт на свой адрес (внутренний номер, очередь, другое
IVR и т.д.).

## Где находится

Меню: **Маршрутизация → IVR**. Кто видит: пользователи с правом `routing` редактируют, остальные только
просматривают.

## Основные понятия

- **Аудио приветствия** — сообщение, воспроизводимое при открытии IVR (должно быть предварительно
  загружено в [Аудиотеку](/docs/audio)).
- **Карта клавиш** — отдельный адрес для каждой клавиши (`0–9`, `*`, `#`). Пустая клавиша — не назначена.
- **Прямой набор** — если включено, звонящий может не дослушивать меню и сразу набрать полный номер
  другого внутреннего номера.
- **По истечении времени / неверная клавиша** — если за отведённое время ничего не нажато или нажата
  незанятая клавиша, воспроизводится соответствующее аудио (необязательно) и переход идёт на отдельный
  адрес.
- **Проверка на петлю (loop)** — если IVR соединяется само с собой напрямую или через другое IVR, система
  выдаёт ошибку и показывает, через какой путь образовалась петля.

## Поля

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| Имя | Название IVR-меню | Не более 128 символов |
| Номер | Необязательно — для прямого набора | 2–10 символов `0-9*#` |
| Аудио приветствия | Сообщение, воспроизводимое при открытии меню | Обязательно |
| Аудио при неверной клавише | Необязательное сообщение | Пусто — при неверной клавише сразу переход на адрес ошибки |
| Время ожидания (сек) | Сколько ждать, если клавиша не нажата | 1–60, по умолчанию 7 |
| Количество повторов | Сколько раз повторяется приветствие по истечении времени | 0–5, по умолчанию 2 |
| Прямой набор | Возможность полностью набрать другой внутренний номер | По умолчанию отключено |
| Карта клавиш | Адрес для каждой клавиши | Должна быть назначена хотя бы 1 клавиша |
| По истечении времени | Адрес, если ничего не нажато | Обязательно |
| При неверной клавише | Адрес, если нажата незанятая клавиша | Обязательно |

В качестве адреса выбирается: внутренний номер, группа вызова, очередь, другое IVR, условие рабочего
времени, конференция, музыка ожидания/занятый сигнал, объявление, особый адрес.

## Как это делается

### Добавление нового IVR
1. Сначала загрузите аудио приветствия в [Аудиотеку](/docs/audio).
2. Нажмите **Добавить IVR**, выберите имя и аудио приветствия.
3. Назначьте адреса нужным клавишам (хотя бы одной) — каждую ячейку можно нажать и выбрать адрес через
   `DestinationPicker`.
4. Назначьте адреса **По истечении времени** и **При неверной клавише** (оба обязательны).
5. Нажмите **Добавить**.

### Изменение или очистка адреса клавиши
1. Откройте IVR на редактирование, нажмите нужную ячейку клавиши, выберите новый адрес.
2. Чтобы освободить клавишу, нажмите значок X рядом с ячейкой.

### Включение прямого набора
1. В редактировании IVR включите кнопку **Прямой набор** — теперь звонящий может не дослушивать меню и
   сразу полностью набрать другой внутренний номер.

### Привязка IVR к входящему маршруту
1. На экране [Входящие маршруты](/docs/inbound) направьте DID-номер на этот IVR.
2. Либо выберите это IVR как адрес на какой-либо клавише другого IVR (для вложенного меню).

### Удаление
1. Нажмите значок корзины в конце строки.
2. Если IVR используется где-то ещё, удаление блокируется — сначала удалите эти связи.

> [!WARNING]
> Если одно IVR выбрано на клавише другого (или в адресе истечения времени/ошибки) и через него
> соединение возвращается само на себя — при сохранении появится ошибка «петля» с указанием пути. В этом
> случае пересмотрите цепочку.

> [!TIP]
> Если поле «Аудио при неверной клавише» оставлено пустым, при нажатии неверной клавиши сообщение не
> воспроизводится, и переход на указанный адрес происходит сразу — это сокращает время ожидания.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| Кнопка «Добавить» неактивна | Не назначена ни одна клавиша или не выбраны адреса времени/ошибки | Заполните хотя бы одну клавишу и оба обязательных адреса |
| Ошибка «петля» при сохранении | IVR соединяется само с собой напрямую или через другое IVR | Проверьте указанный путь и разорвите цепочку |
| Не удаётся удалить IVR | Используется во входящем маршруте или на другой клавише | Сначала удалите эти связи |
| Список выбора аудио пуст | Аудио ещё не загружено | Загрузите файл в [Аудиотеку](/docs/audio) |
