# Наборы PIN

Набор PIN — список PIN-кодов, который привязывается к [исходящему маршруту](/docs/outbound) и запрашивает
у пользователя код перед установкой звонка. В одном наборе может быть несколько PIN — каждому
присваивается отдельная метка (например имя сотрудника), по которой можно отследить, кто звонил с каким
кодом.

## Где находится

Меню: **Подключение → Наборы PIN**. Кто видит: право `connect:view`.
Добавление/редактирование/удаление/управление PIN — право `connect:edit`; при его отсутствии показывается
подсказка **«У вас нет прав на управление наборами PIN — доступен только просмотр»**.

## Основные понятия

- **Набор PIN** — контейнер с именем и настройками (запись в CDR); сам по себе ни на что не влияет,
  начинает действовать после привязки к полю **Набор PIN** [исходящего маршрута](/docs/outbound).
- **Запись в CDR** — если включено, в истории звонков сохраняется, какой PIN (с меткой) был использован —
  позже можно проверить, кто звонил с каким кодом.
- **Каждый PIN** — цифровой код из 4–12 цифр + метка (например имя сотрудника или название отдела). Метка
  обязательна — ввести только цифры нельзя.
- Один PIN не может использоваться в нескольких наборах — при вводе уже занятого PIN появится ошибка.

## Поля

Таблица **Наборов**:

| Столбец | Что показывает |
|---|---|
| **Имя** | Название набора |
| **Запись в CDR** | Включено (✓) или отключено (—) |
| **Кол-во PIN** | Количество PIN в наборе |
| **Где используется** | Названия исходящих маршрутов, использующих этот набор |

Форма **добавления/редактирования набора**:

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| **Имя** | Название для распознавания набора | — (обязательно) |
| **Запись в CDR** | Сохранять использованный PIN в истории звонков | по умолчанию: отключено |

Окно **управления PIN**:

| Поле | Что делает | Пример / по умолчанию |
|---|---|---|
| **Добавить новые PIN** | По одному PIN в строке в формате: `pin;метка` | `1234;Директор` |

## Как это делается

### Создание нового набора PIN
1. Нажмите кнопку **Новый набор**.
2. Введите **Имя**, при необходимости включите **Запись в CDR**.
3. Нажмите кнопку **Добавить**.

### Добавление PIN в набор
1. В таблице в строке нужного набора нажмите значок PIN (ключ).
2. В открывшемся окне в поле **Добавить новые PIN** впишите по одному коду в строке в формате
   `pin;метка` (например `1234;Директор`).
3. Нажмите **Добавить** — при ошибке будет показана строка, в которой она найдена.

### Удаление PIN
1. Откройте набор и в списке PIN в строке нужной метки нажмите кнопку X.

### Привязка набора к исходящему маршруту
1. В разделе [Исходящие маршруты](/docs/outbound) откройте нужный маршрут на редактирование.
2. В поле **Набор PIN** выберите созданный набор, нажмите **Сохранить**.

### Удаление набора
1. В строке нажмите значок **Удалить**.
2. Если набор ещё используется в каком-либо исходящем маршруте, система покажет, в каких именно
   маршрутах, и не разрешит удаление — сначала удалите его из маршрута.

## Советы и ограничения

> [!TIP]
> Рекомендуется создавать отдельный PIN и метку для каждого сотрудника/отдела — тогда при включённой
> **записи в CDR** можно точно увидеть, кто использовал какой маршрут.

> [!WARNING]
> Сам по себе набор PIN ни на что не влияет — он начинает действовать только после привязки к полю
> **Набор PIN** исходящего маршрута.

## Проблемы и решения

| Признак | Причина | Решение |
|---|---|---|
| «Строка {{row}} неверна — формат «PIN;метка»...» | Строка в неверном формате (нет `;`, PIN не из 4–12 цифр или метка пуста) | Пишите каждую строку в виде `1234;Метка` |
| «Этот PIN уже занят» | Введённый код уже используется где-то ещё | Выберите другой код |
| Не удаётся удалить набор | Набор ещё используется в каком-либо исходящем маршруте | Сначала удалите его из указанных маршрутов |
| При звонке PIN не запрашивается | Набор не привязан ни к одному исходящему маршруту | В [Исходящих маршрутах](/docs/outbound) откройте маршрут и выберите **Набор PIN** |
