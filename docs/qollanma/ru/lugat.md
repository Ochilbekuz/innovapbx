# Словарь терминов

Краткое пояснение терминов и сокращений, встречающихся в руководстве — в алфавитном порядке.

| Термин | Пояснение |
|---|---|
| **2FA** | Двухфакторная аутентификация — дополнительно к логину/паролю требует одноразовый код через приложение TOTP (Google Authenticator и т.п.). |
| **API-ключ** | Ключ с ограниченными правами (scope), выдаваемый внешним приложениям для доступа к открытому API `/api/public/v1/*`. |
| **Журнал аудита** | Полная запись о том, кто что сделал в системе (создал/изменил/удалил/вошёл). |
| **BLF** (Busy Lamp Field) | Индикатор на кнопке телефона — показывает занятость/свободность другого внутреннего номера/адреса. |
| **CDR** (Call Detail Record) | Запись о каждом звонке: кто, кому, когда, сколько длился, как завершился. |
| **CID** (Caller ID) | Видимый номер/имя звонящей стороны. |
| **CIDR** | Формат записи сетевого адреса, например `192.168.1.0/24` — обозначает один IP или целую сеть. |
| **Diff (различие)** | Список «что изменится» перед применением изменения на страницах Сеть/Firewall и т.п. |
| **DISA** | Возможность позвонить на номер офиса снаружи, ввести PIN и через транк офиса сделать исходящий звонок на внешний номер. |
| **DND** (Do Not Disturb) | Режим «не беспокоить» — при включении звонки на внутренний номер не поступают. |
| **Draft (черновик)** | На страницах Сеть/Firewall — временное состояние, в котором изменение на экране сохраняется, но не сразу отправляется на сервер. |
| **Follow Me** | Переадресация звонка, пришедшего на внутренний номер, по очереди на другие номера (например мобильный телефон). |
| **IVR** | Голосовое меню — позволяет звонящему выбрать раздел нажатием клавиши. |
| **Конференция** | Зал для звонков с входом по PIN, где могут одновременно общаться несколько участников. |
| **Очередь (queue)** | Механизм, распределяющий звонки между несколькими операторами, при занятости всех — ожидание с музыкой. |
| **NAT** | Отображение устройства из локальной сети в интернете под другим (публичным) IP — требует особого внимания в настройках SIP/RTP. |
| **Paging / Intercom** | Одновременная трансляция голосового сообщения на несколько внутренних номеров набором одного номера. |
| **Парковка (park)** | Временная постановка звонка на «место» для продолжения с другого телефона. |
| **Pickup (перехват)** | Приём звонка, звонящего на другой внутренний номер/группу, со своего телефона с помощью кода. |
| **Набор PIN** | Список PIN-кодов, привязываемый к исходящему маршруту и запрашиваемый перед звонком. |
| **Чёрный список (blacklist)** | Список для автоматического отклонения входящего звонка по номеру звонящего. |
| **Группа вызова (ring group)** | Направление, одновременно звонящее (без очереди) на несколько внутренних номеров при поступлении звонка. |
| **Ревизия** | Запись «истории версий», создаваемая при каждом сохранении настройки — позволяет вернуться к прежнему состоянию. |
| **RTP** (Real-time Transport Protocol) | Протокол передачи аудиопакетов во время звонка (отдельно от сигнализации SIP). |
| **SIP** (Session Initiation Protocol) | Основной протокол, используемый для установления/управления телефонными звонками. |
| **SLA** | Показатель уровня обслуживания, например «процент звонков, на которые ответили в течение заданных секунд». |
| **Toll-fraud** | Риск несанкционированных массовых/дорогих исходящих звонков со счёта внутреннего номера (атака/злоупотребление); предотвращается часовым/суточным лимитом. |
| **TOTP** | Привязанный ко времени одноразовый код — на его основе приложения 2FA генерируют код. |
| **Транк** | SIP-соединение между АТС и телефонным оператором (или другой АТС) — через него проходят внешние звонки. |
| **Вебхук (webhook)** | HTTP-сообщение, автоматически отправляемое на ваш внешний сервер при возникновении события в системе (например завершение звонка). |
| **Код функции** | Действие, выполняемое набором `*`-кода с телефона (голосовая почта, DND, Follow Me и т.д.). |
